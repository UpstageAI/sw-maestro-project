# Test Briefs — persona selection 적절성 수동 평가용

각 brief에 대해 LLM이 어떤 페어를 고르는지 보고, 그 페어가 직관적으로 그 기획안에 적합한지 평가.

사용법:
- Streamlit UI(`streamlit run app.py`) 입력란에 `raw_text` 단락을 통째로 붙여 넣기
- 또는 `scripts\run_demo_trace.ps1 -NoTrace` 안의 sample brief를 임시로 교체해서 실행

각 brief는 (a) 타겟 demographic이 분명해서 적합성을 판단하기 쉬운 것, (b) 100개 풀에 매칭될 만한 다양성을 커버하도록 고름.

---

## Brief 1 — 시니어 건강관리 앱

서비스 적합 페르소나 후보: 60대 이상, 디지털 접근성에 민감한 사용자, 만성질환 / 건강 관심.

### raw_text

```
혼자 사시는 어르신을 위한 건강관리 앱을 만들고 싶습니다.
혈압과 혈당을 큰 글씨로 기록하고, 매일 정해진 시간에 약 복용 알림을 보냅니다.
스마트폰이 익숙하지 않으셔도 음성으로 결과를 듣고, 가족에게 자동으로 일주일 리포트가 갑니다.
가입 절차는 본인 인증 한 번으로 끝나고, 가족이 보호자 계정으로 연결할 수 있습니다.
```

### 구조화 입력 (코드로 직접 호출할 때)

- **title**: 시니어 건강관리 앱
- **target**: 혼자 사는 60대 이상 어르신과 그 가족
- **description**: 혈압/혈당 기록, 음성 안내, 가족 리포트, 보호자 계정 연동
- **key_features**: ["혈압/혈당 큰 글씨 기록", "약 복용 음성 알림", "가족 주간 리포트", "보호자 계정"]
- **concerns**: 스마트폰 사용이 익숙하지 않은 어르신이 끝까지 쓸 수 있는지, 가족 연결 동의 흐름이 까다롭지 않은지

### 평가 체크

- 60대 이상 페르소나가 1명 이상 들어가는가?
- 디지털 접근성 / 작은 글씨 불편함 / 가족 관계 관련 pain_point를 가진 페르소나가 들어가는가?

## Brief 2 — 청년 1인가구 가계부

서비스 적합 페르소나 후보: 20~30대 직장인 / 자취생, 자산 형성/소비 통제에 민감.

### raw_text

```
20-30대 1인가구를 위한 자동 가계부 앱입니다.
은행 계좌와 카드를 한 번만 연결하면 지출이 카테고리별로 자동 분류되고,
"이번 달 외식비 한도 30만 원" 같은 목표를 세우면 초과할 때 푸시로 알려줍니다.
구독료, 통신비, 보험료 등 고정지출은 따로 모아 보여주고,
지난달 대비 늘어난 지출이 무엇인지 한 화면에 요약합니다.
```

### 구조화 입력

- **title**: 1인가구 자동 가계부
- **target**: 20-30대 1인가구 직장인 / 자취생
- **description**: 계좌·카드 자동 연동, 카테고리별 분류, 카테고리 한도 알림, 고정지출 분석
- **key_features**: ["계좌·카드 자동 연동", "카테고리별 자동 분류", "한도 초과 푸시", "고정지출 분석", "전월 대비 요약"]
- **concerns**: 금융 정보 연동에 대한 신뢰, 분류가 정확한지, 알림이 잔소리처럼 느껴지지 않는지

### 평가 체크

- 20-30대 페르소나가 1명 이상 들어가는가?
- 가계 관리 / 자취 / 직장 초기 관련 맥락의 페르소나가 들어가는가?
- 두 명 중 한 명은 보수적인 소비자, 다른 한 명은 자동화에 적극적인 사용자처럼 관점이 갈리는가?

## Brief 3 — 농산물 산지 직거래

서비스 적합 페르소나 후보: 농촌 생산자 (50~70대), 도시 소비자 (30~50대 가족), 신뢰·접근성 양쪽 모두 검증.

### raw_text

```
농촌 생산자와 도시 소비자를 직접 연결하는 산지 직거래 플랫폼입니다.
농가는 사진 한 장과 음성 설명만으로 상품을 등록할 수 있고,
산지에서 바로 포장·배송되어 중간 유통 단계를 없앱니다.
소비자는 농가의 일상 사진과 짧은 영상으로 그 농장이 어떤 곳인지 보고 주문할 수 있고,
배송 후 만족도를 별점과 한 줄로 남기면 다음 시즌 우선 구매권이 생깁니다.
```

### 구조화 입력

- **title**: 농산물 산지 직거래
- **target**: 농촌 고령 생산자 + 도시 소비자 (가족 단위)
- **description**: 음성·사진 등록, 산지 직배송, 농가 일상 콘텐츠, 리뷰 기반 단골
- **key_features**: ["음성·사진으로 상품 등록", "산지 직배송", "농가 일상 콘텐츠", "리뷰 + 단골 권리"]
- **concerns**: 고령 농가가 등록 과정을 끝낼 수 있는지, 도시 소비자가 농가 신뢰를 갖는지, 배송 책임 분쟁

### 평가 체크

- 한 명은 농촌/고령 생산자 관점, 다른 한 명은 도시 소비자 관점인가? (페어로서 관점 차이가 분명한가)
- 디지털 접근성 / 작은 글씨 / 음성 입력 관련 pain_point를 가진 페르소나가 생산자 측에 들어가는가?

## Brief 4 — 워킹맘 식단 관리

서비스 적합 페르소나 후보: 30~40대 여성, 자녀 있음, 시간 부족, 가족 식단 책임감.

### raw_text

```
바쁜 워킹맘을 위한 가족 식단 자동 추천 앱입니다.
일주일 단위로 가족 구성원 수, 알레르기, 좋아하지 않는 재료를 입력하면
저녁 식단 7개와 그에 맞는 장보기 목록이 자동으로 생성됩니다.
주말 1시간 안에 평일 5일치 밑반찬을 만들 수 있는 "주말 한 번 요리" 모드와,
남은 재료로 다음 주 식단을 만들어 음식물 쓰레기를 줄이는 옵션을 제공합니다.
```

### 구조화 입력

- **title**: 가족 식단 자동 추천
- **target**: 30-40대 워킹맘
- **description**: 가족 구성원 정보 기반 주간 식단·장보기 자동화, 주말 일괄 조리, 잔여 재료 활용
- **key_features**: ["주간 식단 자동 생성", "장보기 목록", "주말 일괄 조리 모드", "잔여 재료 식단"]
- **concerns**: 가족이 만족하지 않는 메뉴가 나올 위험, 식단 다양성, 입력 부담

### 평가 체크

- 30-40대 여성 페르소나 / 자녀 있는 가족 관계 페르소나가 들어가는가?
- 두 명 중 한 명은 시간 절약 우선, 다른 한 명은 가족 건강·다양성 우선처럼 관점이 갈리는가?

## Brief 5 — 자영업자 매출 / 재고 자동화

서비스 적합 페르소나 후보: 40~60대 소상공인 / 자영업자, 매출 변동에 민감, 직원·재고 관리 부담.

### raw_text

```
동네 식당, 카페, 작은 가게를 운영하는 자영업자를 위한 매출 / 재고 자동화 도구입니다.
POS 매출과 카드 결제 내역이 자동으로 모이고,
지난주 같은 요일 대비 매출이 얼마나 늘었는지, 어떤 메뉴가 잘 팔렸는지 한눈에 보여줍니다.
재고가 일정 수준 이하로 떨어지면 단골 거래처에 자동으로 주문을 넣고,
직원 출퇴근과 일급 계산도 같은 앱에서 처리합니다.
```

### 구조화 입력

- **title**: 자영업자 매출/재고 자동화
- **target**: 동네 식당·카페·소매점 자영업자 (40-60대)
- **description**: POS 자동 집계, 매출 비교, 재고 자동 발주, 직원·일급 관리
- **key_features**: ["POS·카드 자동 집계", "전주 동일 요일 매출 비교", "재고 자동 발주", "직원 출퇴근/일급"]
- **concerns**: 기존 POS와의 연동, 거래처 변경 시 데이터 이전, 데이터 신뢰

### 평가 체크

- 40-60대 자영업자 / 상인 / 식음료 운영자 페르소나가 들어가는가?
- 두 명 중 한 명은 디지털 자동화에 적극적, 다른 한 명은 사람 관리·관계 중심처럼 관점이 갈리는가?

## 사용 팁

- `raw_text`만 Streamlit UI에 붙여 넣어도 `f0_parse`가 알아서 title/target/key_features를 추출해 줌. 다만 추출 결과가 어색하면 위 "구조화 입력"을 참고해 비교.
- 한 brief를 여러 번 돌리면 LLM 응답이 약간씩 달라질 수 있음. 큰 흐름(예: 시니어 brief에 60대 페르소나가 들어오는지)이 안정적인지 확인하는 게 핵심.
- 결과가 어색하면 `nodes/f1_select.py`의 system 프롬프트를 만져서 (a) 핵심 타겟 적합성 / (b) 잠재 리스크 / (c) 관점 차이 중 어디를 강조할지 조정 가능.

### 후속 plan 후보

- `f1_select`에서 모든 100개 카드를 같은 비중으로 넣기보다, brief target/key_features/concerns와 card summary/goals/pains 간 키워드 기반 pre-rank를 먼저 수행하고 상위 후보를 LLM에 넘기는 방식을 검토한다.
- `pair_reason`뿐 아니라 `per_persona_reasons`에도 카드 demographic과 충돌하는 설명을 금지하는 schema description/prompt 규칙을 추가한다.
- `farm_direct`류처럼 target occupation이 뚜렷한 brief는 후보 중 직업/요약에 관련 키워드가 있는 카드를 최소 1명 포함하도록 fallback 또는 post-validation을 둔다.
