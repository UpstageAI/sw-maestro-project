## 테스트 명세
- **테스트 파일**: `ai/tests/test_article_retriever.py`
- **테스트 이름**: `article_retriever_returns_top_k_from_repository`
- **fixture**: fake repository가 score 포함 article 5개를 반환하고 top_k는 3이다.
- **action**: `ArticleRetriever(repository=fake).retrieve(vector, top_k=3)`를 호출한다.
- **assertions**:
  - 반환 길이가 3이다.
  - score 내림차순이다.
  - 각 item은 `id`, `title`, `content`, `source`, `publishedAt`, `score`를 가진다.
- **mock strategy**: step 테스트는 fake repository를 사용한다. pgvector 실제 검색은 검증 명령의 별도 integration marker로 둔다.
- **out of scope**: context prompt 구성과 token streaming은 후속 step에서 구현한다.

## 구현 기준
- repository interface method는 `search_by_embedding(vector, limit)`로 고정한다.
- integration 검증은 `uv run pytest -m pgvector ai/tests/test_article_retriever_pgvector.py` 명령으로 분리한다.
