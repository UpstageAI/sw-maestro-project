# AI-002 - Solar ChatUpstage 호출 헬퍼

## 목표
실제 LangGraph 노드에서 재사용할 Solar chat wrapper를 만들고, API key 없이도 fake client로 단위 테스트할 수 있게 한다.

## 사전 조건
- `AI-001`의 FastAPI health 테스트가 통과한다.
- `docs/ai/agents.md`의 Solar 사용 정책을 따른다.

## 파일 대상
```text
[신규] ai/src/newspick_ai/solar/chat.py
[신규] ai/tests/test_solar_chat.py
```

## 테스트 명세
- **테스트 파일**: `ai/tests/test_solar_chat.py`
- **테스트 이름**: `chat_solar_uses_injected_client_and_returns_text`
- **fixture**: Fake chat client가 messages 마지막 content `안녕`을 받아 `안녕 응답` 문자열을 반환한다.
- **action**: `SolarChatClient(fake_client).complete([{role:"user", content:"안녕"}])`를 호출한다.
- **assertions**:
  - 반환값이 `안녕 응답`이다.
  - fake client가 받은 model 값이 `solar-pro2`이다.
  - fake client가 받은 첫 message role이 `user`이다.
- **mock strategy**: LangChain ChatUpstage 실제 객체를 만들지 않는다. 생성자 주입 fake client만 사용한다.
- **out of scope**: 요약 프롬프트, streaming, retry 정책은 이 단계에서 구현하지 않는다.

## 구현 기준
- 환경 변수 `UPSTAGE_API_KEY`는 실제 client 생성 시에만 읽는다.
- 테스트는 네트워크를 차단해도 통과해야 한다.
- wrapper public method는 `complete(messages: list[dict]) -> str`로 둔다.

## 검증 방법
`cd ai; uv run pytest ai/tests/test_solar_chat.py`
