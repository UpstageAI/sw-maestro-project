## 테스트 명세
- **테스트 파일**: `ai/tests/test_answer_streamer.py`
- **테스트 이름**: `answer_streamer_yields_token_events_from_fake_solar_stream`
- **fixture**: fake Solar stream이 token `안녕`, `하세요`를 순서대로 yield한다.
- **action**: `AnswerStreamer(chat_client=fake).stream(question, context)`를 async iteration 한다.
- **assertions**:
  - 첫 event 이름이 `token`이다.
  - token text를 합치면 `안녕하세요`이다.
  - 마지막 전까지 done event가 없다.
- **mock strategy**: Solar streaming client fake를 사용한다. 실제 Solar API는 호출하지 않는다.
- **out of scope**: done article cards와 FastAPI endpoint는 AI-028~AI-029에서 구현한다.

## 구현 기준
- prompt에는 question과 context가 모두 포함된다.
- token text는 빈 문자열이면 yield하지 않는다.
