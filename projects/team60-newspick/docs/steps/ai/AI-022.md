# AI-022 - DailyReport 생성/저장 UPSERT

## 목표
date 기준 Daily Report를 생성하고 중복 날짜는 UPSERT로 덮어쓴다.

## 사전 조건

- mockable 외부 의존성 없음.
- hard 외부 의존성 없음.

## 테스트 명세
- **테스트 파일**: `ai/tests/test_report_persistor.py`
- **테스트 이름**: `daily_report_persistor_upserts_same_report_date`
- **fixture**: Testcontainers DB에 `2026-05-12` report를 한 번 저장한 뒤 headline이 다른 report를 같은 date로 다시 저장한다.
- **action**: `DailyReportPersistor.upsert(report)`를 두 번 호출하고 DB를 조회한다.
- **assertions**:
  - `report_date = 2026-05-12` row가 1건이다.
  - headline이 두 번째 값으로 갱신된다.
  - updated_at이 created_at 이상이다.
- **mock strategy**: Testcontainers PostgreSQL과 asyncpg를 사용한다. Solar는 호출하지 않는다.
- **out of scope**: Spring report endpoint는 BE-015~BE-017에서 구현한다.

## 구현 기준
- 중복 `report_date` 정책은 `UPSERT`로 고정한다.
- payload는 `briefing`, `timeline`, `flow`, `keywords`를 모두 포함한다.

## 검증 방법
`cd ai; uv run pytest ai/tests/test_report_persistor.py`
