# AI-005 - RSS 1개 feed 수집 노드

## 목표
네트워크 없이 RSS XML fixture를 파싱해 refresh graph article shape로 변환한다.

## 사전 조건
- `AI-004`의 state와 graph skeleton이 존재한다.
- `docs/architecture/pipeline-design.md`의 collector 책임을 따른다.

## 파일 대상
```text
[신규] ai/src/newspick_ai/graph/collector.py
[신규] ai/tests/fixtures/rss/example-feed.xml
[신규] ai/tests/test_collector.py
```

## 테스트 명세
- **테스트 파일**: `ai/tests/test_collector.py`
- **테스트 이름**: `collector_parses_one_rss_item_into_article_state`
- **fixture**: `example-feed.xml`에 item title `AI 뉴스`, link `https://example.com/ai-news`, pubDate `Tue, 12 May 2026 00:00:00 GMT`, description `요약 후보`를 둔다.
- **action**: `RssCollector(feed_reader=fake_reader).collect(feed_url="fixture://example")`를 호출한다.
- **assertions**:
  - 반환 article의 `url`이 `https://example.com/ai-news`이다.
  - `title`이 `AI 뉴스`이다.
  - `source`가 feed title 또는 `Example Feed`이다.
  - `publishedAt`이 ISO-8601 UTC 문자열이다.
- **mock strategy**: HTTP 요청을 하지 않는다. fake feed reader가 fixture XML 문자열을 반환한다.
- **out of scope**: 여러 feed 병렬 수집, 중복 제거, 본문 추출은 이 단계에서 구현하지 않는다.

## 구현 기준
- 파서는 `feedparser`를 사용한다.
- article id는 URL sha256 앞 16자리로 deterministic하게 만든다.
- category가 없으면 `general`을 넣는다.

## 검증 방법
`cd ai; uv run pytest ai/tests/test_collector.py`
