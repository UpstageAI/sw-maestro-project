## 테스트 명세
- **테스트 파일**: `ai/tests/test_embedder.py`
- **테스트 이름**: `embedder_stores_passage_embedding_vector`
- **fixture**: fake embedding client가 `[0.1,0.2,0.3,0.4]`를 반환하고 Testcontainers DB row `article_001`이 존재한다.
- **action**: `Embedder(embedding_client=fake).run(state)`를 실행하고 DB embedding 컬럼을 조회한다.
- **assertions**:
  - fake client가 article content로 호출된다.
  - DB embedding이 `[0.1,0.2,0.3,0.4]`와 같은 값으로 저장된다.
  - event stage가 `embed`이다.
- **mock strategy**: Embedding client는 fake, DB는 Testcontainers PostgreSQL pgvector를 사용한다.
- **out of scope**: query embedding과 RAG 검색은 AI-024~AI-025에서 다룬다.

## 구현 기준

- 실제 운영 차원은 설정값으로 둔다.
