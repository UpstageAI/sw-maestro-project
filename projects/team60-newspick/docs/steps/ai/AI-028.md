## 테스트 명세
- **테스트 파일**: `ai/tests/test_chat_stream_api.py`
- **테스트 이름**: `chat_stream_endpoint_emits_token_and_done_events`
- **fixture**: fake chat service가 token 2개와 done `{articles:[]}`를 yield한다.
- **action**: httpx ASGI client로 `POST /chat-stream` body `{message:"오늘 뉴스"}`를 streaming 호출한다.
- **assertions**:
  - status 200이다.
  - content-type에 `text/event-stream`이 있다.
  - 본문에 `event: token` 2개와 `event: done` 1개가 있다.
- **mock strategy**: chat service fake를 dependency override로 주입한다. Solar/DB는 호출하지 않는다.
- **out of scope**: retrieval article card 생성은 AI-029에서 구현한다.

## 구현 기준
- blank message는 HTTP 400 JSON error를 반환한다.
- SSE data는 JSON 문자열로 직렬화한다.
