# AI-009 - 본문 추출 node

## 목표
수집된 article URL에서 본문 텍스트를 추출해 state에 채운다.

## 사전 조건
- 같은 트랙 선행 step: AI-008 완료.
- mockable 외부 의존성 없음.
- hard 외부 의존성 없음.

## 파일 대상
```text
[신규] ai/src/newspick_ai/graph/content_extractor.py
[신규] ai/tests/fixtures/html/article_001.html
[신규] ai/tests/test_content_extractor.py
```

## 테스트 명세
- **테스트 파일**: `ai/tests/test_content_extractor.py`
- **테스트 이름**: `content_extractor_extracts_title_and_body_from_html`
- **fixture**: HTML fixture는 `<article>` 안에 title `AI가 바꾼 뉴스 소비`와 본문 paragraph 2개를 가진다.
- **action**: fake HTTP reader가 HTML fixture를 반환하고 `ContentExtractor.run(state)`를 실행한다.
- **assertions**:
  - 출력 article `content`에 `본문 첫 문단`과 `본문 둘째 문단`이 포함된다.
  - content 길이가 50자 이상이다.
  - event stage가 `extract`이고 articleIds에 `article_001`이 있다.
- **mock strategy**: HTTP reader fake를 사용한다. 실제 웹사이트를 호출하지 않는다.
- **out of scope**: paywall 처리와 이미지 추출은 범위 밖이다.

## 구현 기준
- 본문 추출은 trafilatura 또는 readability 계열 라이브러리 하나로 고정한다.
- 추출 실패 시 article status를 `extract_failed`로 둔다.

## 검증 방법
`cd ai; uv run pytest ai/tests/test_content_extractor.py`
