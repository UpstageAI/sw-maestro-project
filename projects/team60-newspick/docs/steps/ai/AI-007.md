# AI-007 - GET /refresh-stream SSE endpoint

## 목표
FastAPI가 refresh graph 진행 이벤트를 SSE로 내보내는 endpoint를 제공한다.

## 사전 조건
- `AI-006`까지의 refresh graph 노드 shape가 고정됐다.
- `docs/contracts/python-ai.yaml`과 `docs/contracts/sse-events.md`의 refresh 이벤트를 따른다.

## 파일 대상
```text
[신규] ai/src/newspick_ai/api/refresh_stream.py
[수정] ai/src/newspick_ai/main.py
[신규] ai/tests/test_refresh_stream.py
```

## 테스트 명세
- **테스트 파일**: `ai/tests/test_refresh_stream.py`
- **테스트 이름**: `refresh_stream_emits_step_and_done_events`
- **fixture**: Fake refresh runner가 `step` event `{stage:"collect", message:"1건 수집"}`와 `done` event `{articleIds:["article_001"]}`를 순서대로 yield한다.
- **action**: httpx ASGI client로 `GET /refresh-stream`를 streaming 호출한다.
- **assertions**:
  - 응답 status가 200이다.
  - content-type에 `text/event-stream`이 포함된다.
  - 본문에 `event: step`과 `collect`가 있다.
  - 본문에 `event: done`과 `article_001`이 있다.
- **mock strategy**: refresh runner만 fake async generator로 주입한다. RSS, Solar, DB는 호출하지 않는다.
- **out of scope**: Spring proxy와 브라우저 refresh UI는 이 단계에서 구현하지 않는다.

## 구현 기준
- SSE 직렬화는 `event: <name>\ndata: <json>\n\n` 형식으로 고정한다.
- endpoint path는 `/refresh-stream`이다.
- 예외 발생 시 `event: error`를 마지막으로 보낸다.

## 검증 방법
`cd ai; uv run pytest ai/tests/test_refresh_stream.py`
