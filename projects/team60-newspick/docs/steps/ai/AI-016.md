## 테스트 명세
- **테스트 파일**: `ai/tests/test_quiz_parser.py`
- **테스트 이름**: `quiz_parser_rejects_missing_answer_field`
- **fixture**: fixture는 정상 JSON, `answer` 누락 JSON, answer 문자열 JSON 3개이다.
- **action**: `parse_quiz_output(raw)`를 각 fixture에 호출한다.
- **assertions**:
  - 정상 JSON은 Quiz 객체 1개를 반환한다.
  - answer 누락은 `QuizParseError`를 던진다.
  - answer 문자열은 `QuizParseError`를 던진다.
- **mock strategy**: 외부 API 없는 순수 parser 테스트다.
- **out of scope**: LLM 재시도 프롬프트는 구현하지 않는다.

- schema는 `id`, `question`, `answer`, `explanation` required로 고정한다.
- unknown field는 무시한다.
