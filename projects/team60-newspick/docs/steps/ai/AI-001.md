# AI-001 — FastAPI 스켈레톤 + /health 엔드포인트

## 목표

`uv run uvicorn newspick_ai.main:app --port 8000` 으로 실행하면 `GET /health` 가 `{"status":"ok"}` 를 반환한다. pytest + httpx 로 검증.

## 테스트 명세

- **테스트 파일**: `ai/tests/test_health.py`
- **테스트 이름**: `test_health_returns_ok`
- **given**: FastAPI app instance
- **when**: `httpx.AsyncClient` 로 `GET /health`
- **then**:
  - status code 200
  - JSON body == `{"status": "ok"}`

## 구현 힌트

- `httpx.AsyncClient(app=app, base_url="http://test")` 패턴 (`from httpx import ASGITransport`):
  ```python
  import pytest
  from httpx import AsyncClient, ASGITransport
  from newspick_ai.main import app

  @pytest.mark.asyncio
  async def test_health_returns_ok():
      async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test") as client:
          response = await client.get("/health")
      assert response.status_code == 200
      assert response.json() == {"status": "ok"}
  ```
- pytest-asyncio 설정 (`pyproject.toml`):
  ```toml
  [tool.pytest.ini_options]
  asyncio_mode = "auto"
  testpaths = ["tests"]
  ```
- main.py:
  ```python
  from fastapi import FastAPI
  app = FastAPI(title="NewPick AI")

  @app.get("/health")
  async def health():
      return {"status": "ok"}
  ```

## 검증 방법

**자동**:
```bash
cd ai
uv run pytest tests/test_health.py -v
```
기대: 1 test pass.

**수동**:
```bash
cd ai
uv run uvicorn newspick_ai.main:app --port 8000 &
curl -s http://localhost:8000/health
```
기대 출력: `{"status":"ok"}`.
