# AI-006 - URL 기준 Deduplicator 노드

## 목표
이미 저장된 URL과 같은 신규 article 후보를 제거한다.

## 사전 조건
- `AI-005`의 collector가 article 후보를 만든다.
- `docs/contracts/db-init.sql`의 `articles.url` unique 정책을 따른다.

## 파일 대상
```text
[신규] ai/src/newspick_ai/graph/deduplicator.py
[신규] ai/tests/test_deduplicator.py
```

## 테스트 명세
- **테스트 파일**: `ai/tests/test_deduplicator.py`
- **테스트 이름**: `deduplicator_removes_articles_with_existing_urls`
- **fixture**: 입력 articles는 `article_dup` url `https://example.com/dup`와 `article_new` url `https://example.com/new` 2개, fake repository existing URLs는 `https://example.com/dup` 1개이다.
- **action**: `Deduplicator(repository=fake_repo).run(state)`를 호출한다.
- **assertions**:
  - 출력 `articles` 길이가 `1`이다.
  - 남은 article id가 `article_new`이다.
  - 출력 `events`에 `dedupe` stage와 dropped count `1`이 있다.
- **mock strategy**: DB를 호출하지 않는다. fake repository가 existing URL set을 반환한다.
- **out of scope**: title 유사도 dedupe, canonical URL 정규화는 이 단계에서 구현하지 않는다.

## 구현 기준
- URL 비교는 완전 일치로 고정한다.
- 입력 순서를 보존한다.
- 중복 제거된 article은 별도 리스트로 반환하지 않는다.

## 검증 방법
`cd ai; uv run pytest ai/tests/test_deduplicator.py`
