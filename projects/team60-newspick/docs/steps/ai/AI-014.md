# AI-014 - refresh graph persisted article IDs

## 목표
refresh graph 완료 이벤트에 저장 완료 article id 목록을 포함한다.

## 사전 조건
- 같은 트랙 선행 step: AI-013 완료.
- mockable 외부 의존성 없음.
- hard 외부 의존성 없음.

```text
[수정] ai/src/newspick_ai/graph/refresh_graph.py

```

## 테스트 명세
- **테스트 파일**: `ai/tests/test_refresh_graph_done_event.py`
- **테스트 이름**: `refresh_stream_done_event_contains_persisted_article_ids`
- **fixture**: fake graph는 persisted ids `article_001`, `article_002`를 반환한다.
- **action**: ASGI client로 `/refresh-stream`을 호출한다.
- **assertions**:
  - SSE 본문에 `event: done`이 있다.
  - done data `articleIds` 배열이 `article_001`, `article_002`를 포함한다.
  - 중복 id가 없다.
- **mock strategy**: graph runner fake를 사용한다. DB와 Solar는 호출하지 않는다.
- **out of scope**: Spring proxy와 FE live gate 실행은 범위 밖이다.

## 구현 기준
- done event payload key는 `articleIds`로 고정한다.
- 빈 결과는 `articleIds: []`로 보낸다.
