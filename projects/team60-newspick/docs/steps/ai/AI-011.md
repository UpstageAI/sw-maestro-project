## 테스트 명세
- **테스트 파일**: `ai/tests/test_summary_validator.py`
- **테스트 이름**: `summary_validator_rejects_empty_or_too_long_summary`
- **fixture**: fixture는 정상 summary 3문장, 빈 summary, 800자 summary 3개 case를 가진다.
- **action**: 각 fixture를 `SummaryValidator.run(state)`에 넣는다.
- **assertions**:
  - 정상 summary는 status `summarized`가 된다.
  - 빈 summary는 status `summary_invalid`가 된다.
  - 800자 summary는 status `summary_invalid`가 된다.
- **mock strategy**: 외부 API를 사용하지 않는 순수 함수 테스트다.
- **out of scope**: LLM judge와 사실성 자동 채점은 범위 밖이다.
