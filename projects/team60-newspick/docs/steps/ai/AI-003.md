# AI-003 - UpstageEmbeddings passage/query 헬퍼

## 목표
본문 저장용 passage embedding과 검색용 query embedding을 분리한 helper를 만든다.

## 사전 조건
- `AI-002`의 SolarChatClient wrapper가 존재한다.
- `docs/ai/agents.md`의 embedding 모델명을 따른다.

## 파일 대상
```text
[신규] ai/src/newspick_ai/solar/embeddings.py
[신규] ai/tests/test_embeddings.py
```

## 테스트 명세
- **테스트 파일**: `ai/tests/test_embeddings.py`
- **테스트 이름**: `embedding_client_uses_passage_and_query_models`
- **fixture**: Fake embedding client가 model 이름별로 길이 4 벡터 `[0.1, 0.2, 0.3, 0.4]`를 반환한다.
- **action**: `embed_passage("본문")`와 `embed_query("질문")`을 각각 호출한다.
- **assertions**:
  - passage 호출 model이 `solar-embedding-1-large-passage`이다.
  - query 호출 model이 `solar-embedding-1-large-query`이다.
  - 두 반환값은 `list[float]`이다.
- **mock strategy**: 실제 UpstageEmbeddings 객체를 만들지 않는다. fake embedding client를 생성자 주입한다.
- **out of scope**: pgvector 저장과 유사도 검색은 `AI-013`, `AI-025`에서 다룬다.

## 구현 기준
- wrapper method는 `embed_passage(text)`와 `embed_query(text)`로 고정한다.
- 빈 문자열 입력은 `ValueError`를 던진다.
- 테스트는 벡터 차원을 4로 줄여 deterministic하게 둔다.

## 검증 방법
`cd ai; uv run pytest ai/tests/test_embeddings.py`
