# AI-023 - Daily report refresh graph 연결

- mockable 외부 의존성 없음.
- hard 외부 의존성 없음.

## 테스트 명세
- **테스트 파일**: `ai/tests/test_daily_report_graph.py`
- **테스트 이름**: `refresh_graph_done_event_contains_report_date`
- **fixture**: fake report generator가 date `2026-05-12`와 report id `report_20260512`를 반환한다.
- **action**: fake graph로 `/refresh-stream`을 호출한다.
- **assertions**:
  - done event data에 `reportDate: "2026-05-12"`가 있다.
  - done event data에 `articleIds`가 유지된다.
  - report generator는 summarized article ids를 입력으로 받는다.
- **mock strategy**: report generator와 DB persistor를 fake로 주입한다. Solar/DB는 호출하지 않는다.
- **out of scope**: FE report live gate는 FE-030에서 수행한다.

## 구현 기준
- report generation은 article persist 이후 실행한다.
- report 실패는 refresh 전체 실패가 아니라 `report_failed` event로 보낸다.
