# FE-019 - 다음 문항 진행

## 목표
여러 O/X 문항을 순서대로 풀 수 있게 한다.

## 사전 조건
- 같은 트랙 선행 step: FE-018 완료.
- mockable 외부 의존성: BE-013, AI-015. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.inline-quiz#inlineQuiz`.
- 스타일 기준: `prototype/styles.css`의 `.quiz-dots`, `.quiz-next-button`, `.question-block`, `.quiz-feedback`.
- 인터랙션 기준: `prototype/script.js`의 `renderQuizQuestion`, `showQuizResult`.
- 보조 색인: `docs/design.md` §4.6, §6. 충돌 시 원본 prototype을 따른다.
- 문항 진행 dots, 다음 문항 button, feedback 초기화 상태를 prototype과 동일하게 맞춘다.

## 테스트 명세
- **테스트 파일**: `frontend/src/components/InlineQuiz.test.tsx`
- **테스트 이름**: `next_question_advances_after_answer`
- **fixture**: quiz fixture 2개: `quiz_001` 질문 `첫 번째 질문`, `quiz_002` 질문 `두 번째 질문`을 사용한다.
- **action**: 첫 번째 문항에서 `O`를 클릭한 뒤 `다음 문항` button을 클릭한다.
- **assertions**:
  - 초기 heading은 `첫 번째 질문`이다.
  - 클릭 후 heading은 `두 번째 질문`이다.
  - 진행 텍스트 `2 / 2`가 보인다.
- **mock strategy**: 컴포넌트 props fixture만 사용한다. API 호출은 없다.
- **out of scope**: 최종 결과 요약과 상세 페이지 삽입은 후속 step에서 구현한다.

## 구현 기준
- 마지막 문항 전에는 `결과 보기`를 노출하지 않는다.
- 문항 전환 때 이전 feedback은 초기화한다.

- prototype `.inline-quiz#inlineQuiz`와 구현 컴포넌트를 나란히 비교한다.
- 첫 문항 선택 후 `다음 문항` 버튼 위치, 색상, 크기가 prototype과 같다.
- 다음 문항으로 이동하면 dots 활성 상태와 feedback 초기화가 prototype 동작과 같다.
