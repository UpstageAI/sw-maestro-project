# FE-020 - 퀴즈 결과 요약

## 목표
모든 문항 완료 후 맞힌 개수와 총 문항 수를 보여준다.

## 사전 조건
- 같은 트랙 선행 step: FE-019 완료.
- mockable 외부 의존성: BE-013, AI-015. 미완료 상태에서도 MSW 또는 fixture로 진행한다.

- 1차 기준: `prototype/index.html`의 `.inline-quiz#inlineQuiz`.

## 테스트 명세
- **테스트 파일**: `frontend/src/components/InlineQuiz.test.tsx`
- **테스트 이름**: `finishing_quiz_shows_result_summary`
- **fixture**: quiz fixture 2개 중 첫 번째는 answer true, 두 번째는 answer false다.
- **action**: 첫 번째 `O`, `다음 문항`, 두 번째 `O`, `결과 보기`를 순서대로 클릭한다.
- **assertions**:
  - heading 또는 status에 `1 / 2`가 보인다.
  - 텍스트 `퀴즈 완료`가 보인다.
  - button role 이름 `다시 풀기`가 보인다.
- **mock strategy**: 컴포넌트 로컬 state만 사용한다. 결과 서버 저장은 하지 않는다.
- **out of scope**: 사용자별 학습 이력 저장은 범위 밖이다.
