# FE-036 - Context suggestions

## 목표
현재 feed/report 맥락 기반 추천 질문을 chat shell에 노출한다.

## 사전 조건
- 같은 트랙 선행 step: FE-035 완료.
- mockable 외부 의존성: BE-022, AI-024. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page.chat-page` 안 `.chat-suggestion-chip`.
- 스타일 기준: `prototype/styles.css`의 `.chat-intro`, `.chat-suggestions`, `.chat-suggestion-chip`, `.chat-input`.
- 인터랙션 기준: `prototype/script.js`의 suggestion click 흐름.
- 보조 색인: `docs/design.md` §4.8, §5.1, §6. 충돌 시 원본 prototype을 따른다.
- 추천 질문 chip 텍스트, wrapping, click 후 input 채움 상태를 prototype과 동일하게 맞춘다.

[신규] frontend/src/features/chat/suggestions.ts

## 테스트 명세
- **테스트 파일**: `frontend/src/features/chat/suggestions.test.ts`
- **테스트 이름**: `suggestions_include_category_and_report_context`
- **fixture**: context fixture `{page:"feed", category:"tech", topKeyword:"AI"}`를 사용한다.
- **action**: `buildChatSuggestions(context)`를 호출한다.
- **assertions**:
  - 반환 배열 첫 항목이 `AI 관련 핵심 기사 알려줘`이다.
  - 배열 길이가 3 이하이다.
  - 각 suggestion은 40자 이하이다.
- **mock strategy**: 순수 함수 테스트만 사용한다. API 호출은 없다.
- **out of scope**: 개인화 추천과 서버 저장은 범위 밖이다.

## 구현 기준
- suggestion 클릭 시 input에 해당 문장을 채우고 submit하지 않는다.
- 중복 suggestion은 제거한다.

`cd frontend; pnpm lint`

## 수동 브라우저 검증
- /feed chat에서 추천 질문을 선택하면 입력창에 문장이 채워진다.
- prototype chat 화면과 구현 화면을 나란히 비교한다.
- suggestion chip의 radius, border, padding, 줄바꿈과 선택 후 input 상태가 prototype과 같다.
