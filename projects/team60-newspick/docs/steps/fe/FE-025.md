# FE-025 - Report timeline section

## 목표
Daily Report의 시간순 기사 흐름을 timeline으로 표시한다.

## 사전 조건
- 같은 트랙 선행 step: FE-024 완료.
- mockable 외부 의존성: BE-016, AI-019. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

- 1차 기준: `prototype/index.html`의 `.app-page[data-page="report"]` 안 `.timeline`.
- 확정 변형 기준: `prototype/report-variations.jsx`의 `VariantCPlus`.
- 스타일 기준: `prototype/styles.css`의 `.tl-head`, `.timeline`, `.tl-rail`, `.tl-item--big`, `.tl-node`, `.tl-card`.
- 보조 색인: `docs/design.md` §4.7, §5.2, §5.5. 충돌 시 원본 prototype을 따른다.
- timeline rail, headline node, category color, media count badge, card hierarchy를 prototype과 동일하게 맞춘다.
