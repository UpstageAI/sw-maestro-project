# FE-034 - Done article cards rendering

## 목표
chat done 이벤트의 articles 배열을 참고 기사 카드로 표시한다.

## 사전 조건
- 같은 트랙 선행 step: FE-033 완료.
- mockable 외부 의존성: BE-020, AI-029. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page.chat-page`.
- 스타일 기준: `prototype/styles.css`의 `.chat-article-card`, `.chat-source-label`, `.chat-bubble--ai`.
- 인터랙션 기준: `prototype/script.js`의 chat response article card 삽입 흐름.
- 보조 색인: `docs/design.md` §4.8, §5.2, §6. 충돌 시 원본 prototype을 따른다.
- 참고 기사 card의 title/source/time, source label, card radius, spacing을 prototype과 동일하게 맞춘다.

## 테스트 명세
- **테스트 파일**: `frontend/src/features/chat/ChatArticleCards.test.tsx`
- **테스트 이름**: `chat_article_cards_render_article_summary_links`
- **fixture**: ArticleCardSummary fixture 2개: `article_001`, `article_002`와 title/source/publishedAt을 사용한다.
- **action**: `ChatArticleCards`에 fixture를 전달한다.
- **assertions**:
  - list role 이름 `참고 기사`가 있다.
  - listitem이 2개이다.
  - link role 이름이 `AI가 바꾼 뉴스 소비`를 포함하고 href가 `/articles/article_001`이다.
  - 텍스트 `Example News`와 `2026.05.12`가 보인다.
- **mock strategy**: 컴포넌트 props fixture만 사용한다. 실제 SSE는 호출하지 않는다.
- **out of scope**: 카드 클릭 후 상세 페이지 live 검증은 이 단계 범위 밖이다.

## 구현 기준
- 계약 schema는 `docs/contracts/json-schemas/article-card-summary.json`을 따른다.
- source와 publishedAt이 없으면 card를 렌더링하지 않고 console error를 남긴다.
