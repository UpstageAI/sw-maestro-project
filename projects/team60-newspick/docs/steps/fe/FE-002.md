# FE-002 - Splash Page

## 목표

사용자가 첫 화면에서 NewPick 브랜드, 짧은 서비스 설명, "서비스 시작하기" CTA를 볼 수 있다.

## 사전 조건

- BOOT-000 완료
- FE-001 완료
- `frontend/` Next.js 앱과 Tailwind v4 토큰이 동작한다.

## 파일 대상

```
frontend/app/page.tsx                       [수정]
frontend/__tests__/page.test.tsx            [신규]
frontend/package.json                       [수정 - Testing Library 의존성]
frontend/pnpm-lock.yaml                     [수정]
frontend/public/newspick.png                [신규 - prototype/assets/newspick.png 복사]
```

## 테스트 명세

- **테스트 파일**: `frontend/__tests__/page.test.tsx`
- **테스트 이름**: `renders_splash_page`
- **given**: `app/page.tsx`의 `Home` 컴포넌트
- **when**: Testing Library로 렌더링
- **then**:
  - `NewPick` heading이 보인다.
  - intro 텍스트 `AI가 오늘의 뉴스를 골라 짧게 요약하고 퀴즈로 정리해요.`가 보인다.
  - `서비스 시작하기` 버튼이 보인다.
  - NewPick 로고 이미지의 accessible name이 `NewPick logo`로 노출된다.

## 구현 힌트

- `docs/design.md`의 스플래시 명세를 기준으로 한다.
- 기존 create-next-app 기본 화면은 제거한다.
- 로고는 `prototype/assets/newspick.png`를 `frontend/public/newspick.png`로 복사해서 사용한다.
- 페이지는 아직 실제 라우팅 동작을 연결하지 않고, CTA는 버튼으로만 렌더링한다. 카테고리 이동은 FE-003에서 구현한다.
- Tailwind 토큰은 FE-001에서 만든 `bg-bg`, `text-ink`, `bg-brand-500` 등만 사용한다.

## 검증 방법

**자동 테스트**:
```bash
cd frontend
pnpm test
```
기대: `page.test.tsx` 포함 전체 테스트 통과.

**정적 검사**:
```bash
cd frontend
pnpm lint
```
기대: 오류 없음.

**수동 확인**:
```bash
cd frontend
pnpm dev
```
브라우저에서 `http://localhost:3000`을 열고 다음을 확인한다.
- NewPick 로고와 `NewPick` 제목이 보인다.
- intro 문구가 보인다.
- 하단에 `서비스 시작하기` 버튼이 보인다.
