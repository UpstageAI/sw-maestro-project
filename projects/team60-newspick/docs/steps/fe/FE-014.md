# FE-014 - 상세 페이지 error/404 상태

## 목표
상세 API 실패와 404를 사용자가 회복 가능한 화면으로 보여준다.

## 사전 조건
- 같은 트랙 선행 step: FE-013 완료.
- mockable 외부 의존성: BE-009, AI-009. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[수정] frontend/src/pages/ArticleDetailPage.tsx
[수정] frontend/src/pages/ArticleDetailPage.test.tsx
[수정] frontend/src/api/articles.ts
```

## 테스트 명세
- **테스트 파일**: `frontend/src/pages/ArticleDetailPage.test.tsx`
- **테스트 이름**: `article_detail_page_shows_not_found_message_for_404`
- **fixture**: MSW `GET /api/articles/missing-id`가 404 `{code:"ARTICLE_NOT_FOUND", message:"기사를 찾을 수 없습니다"}`를 반환한다.
- **action**: MemoryRouter initial entry `/articles/missing-id`로 렌더링한다.
- **assertions**:
  - role `alert`가 보인다.
  - 텍스트 `기사를 찾을 수 없습니다`가 보인다.
  - button 또는 link role 이름 `피드로 돌아가기`가 보인다.
- **mock strategy**: MSW error handler를 사용한다. 실제 서버 장애는 재현하지 않는다.
- **out of scope**: retry 버튼과 offline cache는 이 단계에서 구현하지 않는다.

## 구현 기준
- 404와 500 메시지는 구분한다.
- alert 영역은 스크린 리더가 읽을 수 있게 한다.

`cd frontend; pnpm test -- ArticleDetailPage.test.tsx articles.test.ts`
`cd frontend; pnpm lint`
