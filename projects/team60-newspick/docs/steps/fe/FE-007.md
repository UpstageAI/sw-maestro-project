## 테스트 명세

- **테스트 파일**: `frontend/__tests__/feed-loading-progress.test.tsx`
- **테스트 이름**: `renders_collect_and_summarize_progress`
- **given**: refresh store에 `collect: 7/12`, `summarize: 3/8` 진행값이 있다.
- **when**: `FeedLoadingProgress`를 렌더링한다.
- **then**:
  - `주요 뉴스 수집`, `7 / 12 매체`가 보인다.
  - `AI 요약 생성`, `3 / 8 기사`가 보인다.

- **테스트 파일**: `frontend/__tests__/feed-page.test.tsx`
- **테스트 이름**: `updates_loading_progress_from_sse_step_events`
- **given**: `GET /api/feed` 응답이 지연되고 fake `EventSource`가 있다.
- **when**: `/feed` 페이지를 렌더링한 뒤 `collect`, `summarize` step 이벤트를 발생시킨다.
- **then**: 로딩 카운터가 `7 / 12 매체`, `3 / 8 기사`로 갱신된다.

## 구현 힌트

- `useRefreshStore`는 `collect`, `summarize`, `status`를 가진다.
- `setStep(step, current, total)`로 SSE `step` 이벤트를 반영한다.
- `reset()`으로 로딩 시작 전 값을 초기화한다.
- `FeedLoadingProgress`는 기존 `오늘의 뉴스를 정리 중이에요...` 카드 안에 2단계 카운터를 표시한다.
- `/feed`는 TanStack Query 로딩 중일 때만 `/api/refresh-stream`을 구독한다.
- 테스트 환경처럼 `EventSource`가 없으면 구독을 건너뛰되, UI는 기본 `0 / 12`, `0 / 8` 상태를 보여준다.
