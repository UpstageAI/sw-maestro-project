# FE-005 - Feed Page

## 목표

사용자가 `/feed`에서 오늘의 뉴스 피드 화면을 열 수 있고, TanStack Query로 `/api/feed` 응답을 가져오며 로딩 상태와 빈 응답 상태를 확인할 수 있다.

## 테스트 명세

- **테스트 파일**: `frontend/__tests__/feed-page.test.tsx`
- **테스트 이름**: `shows_loading_state_before_feed_response`
- **given**: MSW가 `GET /api/feed` 응답을 지연한다.
- **when**: `/feed` 페이지 컴포넌트를 렌더링한다.
- **then**: `오늘의 뉴스를 정리 중이에요...` 로딩 문구가 보인다.

- **테스트 파일**: `frontend/__tests__/feed-page.test.tsx`
- **테스트 이름**: `shows_empty_state_when_feed_has_no_articles`
- **given**: MSW가 `GET /api/feed`에 `{ articles: [] }`를 반환한다.
- **when**: `/feed` 페이지 컴포넌트를 렌더링하고 응답 완료를 기다린다.
- **then**: `아직 보여줄 뉴스가 없어요` 빈 상태 문구와 활성 하단 네비 `홈`이 보인다.

## 구현 힌트

- `@tanstack/react-query`의 `useQuery`를 사용하고 query key는 `["feed"]`로 둔다.
- API fetcher는 `frontend/lib/api/feed.ts`에 두고, 기본 API base는 `NEXT_PUBLIC_API_BASE ?? "http://localhost:8080"`로 둔다.
- MSW handler는 `GET */api/feed`를 모킹하고 기본 응답은 `{ articles: [] }`로 둔다.
- 개발 브라우저에서는 `app/providers.tsx`에서 MSW worker를 시작한 뒤 앱을 렌더링한다.
- 이번 step에서는 실제 뉴스 카드 디자인 1대1 포팅을 하지 않는다. FE-008에서 NewsCard를 별도로 구현한다.

## 결정 완료 테스트 명세

- **테스트 이름**: `feed_page_shows_loading_then_empty_state_from_msw`
- **fixture**: MSW `GET /api/feed` 응답 `{articles: []}`와 delay 100ms.
- **action**: `/feed` 페이지를 렌더링하고 loading 후 empty state를 기다린다.
- **assertions**:
  - 초기 role `status` 이름 `뉴스 불러오는 중`이 보인다.
  - 응답 후 empty state copy가 보인다.
  - article role 요소가 0개다.
- **mock strategy**: MSW로 Spring API를 대체한다. 실제 BE 서버는 호출하지 않는다.
- **out of scope**: 기사 카드 디자인과 상세 이동은 FE-008 이후에서 구현한다.
