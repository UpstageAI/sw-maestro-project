# FE-031 - Chat shell layout

## 목표
Feed 안에서 AI chat shell을 열고 닫을 수 있는 기본 레이아웃을 만든다.

## 사전 조건
- 같은 트랙 선행 step: FE-029 완료. FE-030 live integration gate는 BE/AI 준비 후 별도로 검증한다.
- mockable 외부 의존성: BE-018, AI-024. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page.chat-page`.
- 스타일 기준: `prototype/styles.css`의 `.chat-header`, `.chat-intro`, `.chat-suggestion-chip`, `.chat-input-bar`, `.chat-send-btn`.
- 보조 색인: `docs/design.md` §4.8, §5.1, §5.2. 충돌 시 원본 prototype을 따른다.
- 챗 헤더, empty state, 추천 질문, 입력바, panel width와 spacing을 prototype과 동일하게 맞춘다.

## 테스트 명세
- **테스트 파일**: `frontend/src/features/chat/ChatShell.test.tsx`
- **테스트 이름**: `chat_shell_renders_empty_state_and_input`
- **fixture**: ChatShell props는 빈 message 배열과 suggestion `오늘 뉴스 요약해줘` 1개를 가진다.
- **action**: `ChatShell`을 렌더링한다.
- **assertions**:
  - complementary role 이름 `AI 뉴스 챗`이 있다.
  - textbox role 이름 `메시지 입력`이 있다.
  - button role 이름 `보내기`가 disabled 상태다.
  - 텍스트 `오늘 뉴스 요약해줘`가 보인다.
- **mock strategy**: 컴포넌트 props fixture만 사용한다. SSE/API 호출은 하지 않는다.
- **out of scope**: token streaming과 article card는 후속 step에서 구현한다.

## 구현 기준
- shell width는 desktop에서 360px, mobile에서 full width drawer로 둔다.
- 닫기 button accessible name은 `챗 닫기`이다.

`cd frontend; pnpm lint`

- header, intro icon, title/subtitle, suggestion chip, input bar의 구조와 spacing이 prototype과 같다.
