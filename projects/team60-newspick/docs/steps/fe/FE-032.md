# FE-032 - Chat input submit state

## 목표
사용자 메시지 입력, submit, pending 상태를 구현한다.

## 사전 조건
- 같은 트랙 선행 step: FE-031 완료.
- mockable 외부 의존성: BE-019, AI-024. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page.chat-page`.
- 스타일 기준: `prototype/styles.css`의 `.chat-messages`, `.chat-bubble--user`, `.chat-bubble--ai`, `.chat-input`, `.chat-send-btn`.
- 인터랙션 기준: `prototype/script.js`의 `sendMessage` 흐름.
- 보조 색인: `docs/design.md` §4.8, §6. 충돌 시 원본 prototype을 따른다.
- 사용자 말풍선, pending assistant 상태, input submit 상태를 prototype과 동일하게 맞춘다.

## 테스트 명세
- **테스트 파일**: `frontend/src/features/chat/ChatShell.test.tsx`
- **테스트 이름**: `submitting_chat_input_adds_user_message_and_pending_assistant`
- **fixture**: 사용자가 textbox에 `오늘 AI 뉴스 알려줘`를 입력한다. onSubmit fake는 pending promise를 반환한다.
- **action**: textbox 입력 후 `보내기` button을 클릭한다.
- **assertions**:
  - user message `오늘 AI 뉴스 알려줘`가 보인다.
  - assistant pending bubble role `status` 이름 `답변 생성 중`이 보인다.
  - pending 중 보내기 button이 disabled 상태다.
- **mock strategy**: submit handler를 fake로 주입한다. 실제 SSE 호출은 하지 않는다.
- **out of scope**: SSE token 병합과 error retry는 후속 step에서 구현한다.

## 구현 기준
- Enter key submit과 Shift+Enter 줄바꿈을 모두 테스트한다.
- 빈 문자열 submit은 무시한다.
