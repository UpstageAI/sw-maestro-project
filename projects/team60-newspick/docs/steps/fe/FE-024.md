# FE-024 - Report briefing section

## 목표
Daily Report 화면 상단에 headline과 핵심 요약을 렌더링한다.

## 사전 조건
- 같은 트랙 선행 step: FE-023 완료.
- mockable 외부 의존성: BE-015, AI-018. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page[data-page="report"]`.
- 확정 변형 기준: `prototype/report-variations.jsx`의 `VariantCPlus`.
- 스타일 기준: `prototype/styles.css`의 `.report-top`, `.report-day`, `.report-briefing-v2`, `.briefing-label`.
- 보조 색인: `docs/design.md` §4.7, §5.5. 충돌 시 원본 prototype을 따른다.
- 리포트 상단 날짜, 업데이트 시간, 브리핑 카드의 구조, 색상, radius, spacing을 prototype과 동일하게 맞춘다.

- **테스트 파일**: `frontend/src/pages/DailyReportPage.test.tsx`
- **테스트 이름**: `daily_report_page_renders_briefing_headline`
- **fixture**: report fixture date `2026-05-12`, briefing headline `오늘의 핵심`, summary `세 가지 흐름`을 사용한다.
- **action**: MemoryRouter initial entry `/report/2026-05-12`로 렌더링한다.
- **assertions**:
  - heading level 1 이름이 `오늘의 리포트`이다.
  - heading level 2 이름이 `오늘의 핵심`이다.
  - 텍스트 `세 가지 흐름`이 보인다.
- **mock strategy**: MSW report handler를 사용한다. 실제 서버는 호출하지 않는다.
