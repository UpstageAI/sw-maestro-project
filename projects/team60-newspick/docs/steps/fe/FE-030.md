# FE-030 - Daily Report live integration gate

## 목표
Daily Report 전체 계약을 fixture 기반으로 검증하고 live 검증은 명시적 환경 변수에서만 실행한다.

## 사전 조건
- 같은 트랙 선행 step: FE-029 완료.
- mockable 외부 의존성 없음.
- hard 외부 의존성: BE-017, AI-023. 미완료 상태에서는 구현 전에 중단한다.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page[data-page="report"]`.
- 확정 변형 기준: `prototype/report-variations.jsx`의 `VariantCPlus`.
- 스타일 기준: `prototype/styles.css`의 report 관련 class 전체와 `.bottom-nav`.
- 보조 색인: `docs/design.md` §4.7, §4.9, §5.5. 충돌 시 원본 prototype을 따른다.
- fixture와 live 응답 모두 briefing, timeline, flow, keyword cloud, footer mark를 prototype과 동일하게 렌더링해야 한다.

## 파일 대상
```text
[신규] frontend/src/contracts/daily-report.contract.test.ts
[수정] frontend/src/mocks/fixtures/reports.ts
```

## 테스트 명세
- **테스트 파일**: `frontend/src/contracts/daily-report.contract.test.ts`
- **테스트 이름**: `daily_report_contract_fixture_renders_full_report`
- **fixture**: `docs/contracts/json-schemas/daily-report.json`에 맞는 `2026-05-12.report.json` fixture를 사용한다.
- **action**: 기본 테스트는 fixture schema와 `/report/2026-05-12` 렌더링을 검증한다. `RUN_LIVE_CONTRACT=true`일 때만 실제 서버를 호출한다.
- **assertions**:
  - 기본 `pnpm test`는 실제 서버 없이 통과한다.
  - fixture 기반 화면에 briefing, timeline, flow, keywords가 모두 보인다.
  - live `/api/report/2026-05-12` 응답이 schema required field를 모두 가진다.
- **mock strategy**: 기본은 MSW fixture와 JSON schema validator다. live mode는 `RUN_LIVE_CONTRACT=true`에서만 실제 서버를 호출한다.
- **out of scope**: BE-017 또는 AI-023이 미완료이면 live mode와 이 step 구현은 진행하지 않는다.

## 구현 기준
- hard dependency `BE-017`, `AI-023` 완료 전에는 구현 전에 중단한다.
- live 준비 조건: FE `http://localhost:3000`, BE `http://localhost:8080`, AI `http://localhost:8000`, DB daily_report `2026-05-12`.
- 실패 기준: report 404, schema 누락, 주요 섹션 미표시.

## 검증 방법
`cd frontend; pnpm test -- daily-report.contract.test.ts`
`cd frontend; pnpm lint`
`RUN_LIVE_CONTRACT=true pnpm test -- daily-report.contract.test.ts`

## 수동 브라우저 검증
- /report/2026-05-12에서 fixture 기반 briefing, timeline, flow, keyword cloud가 모두 보인다.
- prototype report 화면과 구현 화면을 나란히 비교한다.
- briefing, timeline, flow, keyword cloud, footer mark의 텍스트, 구조, 색상, 간격, radius, shadow가 `VariantCPlus`와 같다.
