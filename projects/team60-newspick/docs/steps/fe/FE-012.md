# FE-012 - 카드에서 상세 페이지 이동

## 목표
Feed card 클릭 또는 키보드 activation으로 상세 페이지로 이동한다.

## 사전 조건
- 같은 트랙 선행 step: FE-011 완료.
- mockable 외부 의존성: BE-009, AI-009. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[수정] frontend/src/components/ArticleCard.tsx
[수정] frontend/src/pages/FeedPage.test.tsx
[신규] frontend/src/navigation/articleNavigation.test.tsx
```

## 테스트 명세
- **테스트 파일**: `frontend/src/navigation/articleNavigation.test.tsx`
- **테스트 이름**: `clicking_article_card_navigates_to_detail_route`
- **fixture**: MSW feed fixture 3건과 detail fixture `article_001`을 사용한다.
- **action**: `/feed`에서 기사 title link를 클릭한다.
- **assertions**:
  - 현재 route가 `/articles/article_001`이 된다.
  - 상세 heading `AI가 바꾼 뉴스 소비`가 보인다.
  - 카드 link는 accessible name에 기사 title을 포함한다.
- **mock strategy**: MSW와 MemoryRouter만 사용한다. 브라우저 실제 history는 호출하지 않는다.
- **out of scope**: 상세 API 404와 loading skeleton은 후속 step에서 구현한다.

## 구현 기준
- 카드는 `<a>` 또는 router `Link`로 구현한다.
- click target은 카드 전체가 아니라 제목 link와 카드 action 영역으로 제한한다.

## 검증 방법
`cd frontend; pnpm test -- articleNavigation.test.tsx FeedPage.test.tsx`
`cd frontend; pnpm lint`

## 수동 브라우저 검증
- /feed에서 첫 카드 제목을 선택하면 `/articles/article_001`로 이동한다.
