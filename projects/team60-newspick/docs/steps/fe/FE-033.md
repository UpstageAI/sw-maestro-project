# FE-033 - SSE token bubble rendering

## 목표
chat-stream의 token event를 하나의 assistant bubble로 누적 표시한다.

## 사전 조건
- 같은 트랙 선행 step: FE-032 완료.
- mockable 외부 의존성: BE-020, AI-027. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page.chat-page`.
- 스타일 기준: `prototype/styles.css`의 `.chat-bubble--ai`, `.chat-typing`, `.chat-messages`.
- 인터랙션 기준: `prototype/script.js`의 typing indicator와 message append 흐름.
- 보조 색인: `docs/design.md` §4.8, §6. 충돌 시 원본 prototype을 따른다.
- token 누적 중 AI bubble, typing dots, message spacing을 prototype과 동일하게 맞춘다.

## 테스트 명세
- **테스트 파일**: `frontend/src/features/chat/chatStream.test.ts`
- **테스트 이름**: `chat_stream_accumulates_token_events_into_assistant_message`
- **fixture**: MSW 또는 fake EventSource가 `token` event data `{text:"안녕"}`, `{text:"하세요"}`, `done` event `{articles:[]}`를 순서대로 보낸다.
- **action**: `startChatStream({message:"hi"})`를 실행하고 이벤트를 모두 소비한다.
- **assertions**:
  - assistant message text가 `안녕하세요`로 합쳐진다.
  - done 이벤트 후 stream 상태가 `closed`이다.
  - token event마다 별도 bubble을 만들지 않는다.
- **mock strategy**: EventSource adapter를 fake로 주입한다. 실제 `/api/chat-stream`은 호출하지 않는다.
- **out of scope**: article cards와 live integration은 후속 step에서 구현한다.

## 구현 기준
- SSE event parser는 event name과 JSON data를 분리한다.
- token text가 빈 문자열이면 무시한다.
