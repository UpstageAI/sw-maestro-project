# FE-016 - Article detail live integration gate

## 목표
MSW 기준 상세 화면을 실제 FE/BE/AI 계약 fixture와 비교하고, live 검증은 명시적 환경 변수에서만 실행한다.

## 사전 조건
- 같은 트랙 선행 step: FE-015 완료.
- mockable 외부 의존성 없음.
- hard 외부 의존성: BE-012, AI-014. 미완료 상태에서는 구현 전에 중단한다.

## 파일 대상
```text
[신규] frontend/src/contracts/article-detail.contract.test.ts
[수정] frontend/src/api/articles.ts
```

## 테스트 명세
- **테스트 파일**: `frontend/src/contracts/article-detail.contract.test.ts`
- **테스트 이름**: `article_detail_contract_fixture_matches_rendered_page`
- **fixture**: `docs/contracts/json-schemas/article.json`에 맞는 `article_001.detail.json` fixture와 MSW detail 응답을 사용한다.
- **action**: 기본 테스트에서는 fixture를 schema 검증한 뒤 상세 페이지를 렌더링한다. `RUN_LIVE_CONTRACT=true`일 때만 실제 `FE_BASE_URL`, `BE_BASE_URL`, `AI_BASE_URL`을 읽어 live endpoint를 호출한다.
- **assertions**:
  - 기본 `pnpm test`는 실제 서버 없이 통과한다.
  - fixture 기반 화면에 title, source, content 첫 문단이 보인다.
  - live mode에서 `/api/articles/article_001` 응답 schema가 fixture와 같은 required field를 가진다.
- **mock strategy**: 기본은 MSW와 JSON schema validator다. live mode는 `RUN_LIVE_CONTRACT=true`일 때만 실제 서버를 호출한다.
- **out of scope**: BE-012 또는 AI-014가 미완료이면 live mode를 실행하지 않는다.

## 구현 기준
- hard dependency `BE-012`, `AI-014`가 progress에서 완료되기 전 이 step은 구현 전에 중단한다.
- live 준비 조건: FE `http://localhost:3000`, BE `http://localhost:8080`, AI `http://localhost:8000`, DB seed `article_001`.
- 실패 기준: schema required field 누락, HTTP 5xx, 화면 heading 미표시.

## 검증 방법
`cd frontend; pnpm test -- article-detail.contract.test.ts`
`cd frontend; pnpm lint`
`RUN_LIVE_CONTRACT=true pnpm test -- article-detail.contract.test.ts`

## 수동 브라우저 검증
- /articles/article_001에서 live mode가 꺼져 있어도 fixture 기반 상세 화면이 통과한다.
