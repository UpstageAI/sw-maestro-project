# FE-023 - Daily Report fetcher

## 목표
일자별 Daily Report API fetcher와 404 처리 모델을 만든다.

## 사전 조건
- 같은 트랙 선행 step: FE-021 완료. FE-022 live integration gate는 BE/AI 준비 후 별도로 검증한다.
- mockable 외부 의존성: BE-015, AI-018. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## API 전용 기준
- 이 step은 Daily Report fetcher와 MSW 응답 모델만 다룬다.
- UI formatting, section ordering, 화면 텍스트, layout 결정은 하지 않는다.
- prototype fidelity 검증은 FE-024~FE-030 화면 step에서 수행한다.
- fetcher는 후속 화면 step이 `prototype/index.html`의 report 화면과 `VariantCPlus`를 그대로 포팅할 수 있도록 contract shape를 보존한다.

## 테스트 명세
- **테스트 파일**: `frontend/src/api/reports.test.ts`
- **테스트 이름**: `fetchDailyReport_returns_report_for_date`
- **fixture**: MSW `GET /api/report/2026-05-12` 응답은 `date`, `briefing`, `timeline`, `flow`, `keywords`를 포함한다.
- **action**: `fetchDailyReport("2026-05-12")`를 호출한다.
- **assertions**:
  - 반환 `date`가 `2026-05-12`이다.
  - `briefing.headline`이 `오늘의 핵심`이다.
  - 404 응답은 `DailyReportNotFoundError`를 throw한다.
- **mock strategy**: MSW node server를 사용한다. 실제 BE/AI 서버는 호출하지 않는다.
- **out of scope**: 리포트 페이지 레이아웃은 다음 step부터 구현한다.

## 구현 기준
- date parameter는 `YYYY-MM-DD` 문자열로 고정한다.
- fetcher는 UI formatting을 하지 않는다.
