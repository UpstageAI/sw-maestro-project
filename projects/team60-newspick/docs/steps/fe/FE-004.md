# FE-004 - PhoneFrame and BottomNav

## 목표

앱 화면들이 공통 모바일 프레임과 하단 네비게이션을 재사용할 수 있도록 `PhoneFrame`과 `BottomNav` 컴포넌트를 제공한다.

## 테스트 명세

- **테스트 파일**: `frontend/__tests__/phone-frame.test.tsx`
- **테스트 이름**: `renders_status_area_and_children`
- **given**: `PhoneFrame`에 본문 children을 전달한다.
- **when**: Testing Library로 렌더링한다.
- **then**:
  - status area의 `9:41`, `5G 100%`가 보인다.
  - children으로 전달한 본문이 보인다.

- **테스트 파일**: `frontend/__tests__/bottom-nav.test.tsx`
- **테스트 이름**: `renders_navigation_items_with_active_page`
- **given**: `BottomNav`에 `active="home"`을 전달한다.
- **when**: Testing Library로 렌더링한다.
- **then**:
  - `홈`, `챗`, `리포트` 네비게이션 링크가 보인다.
  - `홈` 링크의 `aria-current`가 `page`다.
  - `챗`, `리포트` 링크는 `aria-current`가 없다.

## 구현 힌트

- `PhoneFrame`은 prototype의 `.phone-frame` 메타포를 Tailwind 유틸리티로 옮긴다.
- `PhoneFrame`은 기본적으로 status area를 렌더링하고, `children`을 프레임 안에 배치한다.
- `BottomNav`는 홈(`/feed`), 챗(`/chat`), 리포트(`/report`) 3개 링크를 렌더링한다.
- active 상태는 `active: "home" | "chat" | "report"` prop으로 제어한다.
- 이번 step에서는 `/feed`, `/chat`, `/report` 페이지 자체는 만들지 않는다.
- 카테고리 페이지의 기존 프레임 markup은 `PhoneFrame`으로 교체하되 화면 동작과 텍스트는 유지한다.
