# FE-027 - Keyword cloud section

## 목표
Daily Report 키워드를 빈도/중요도에 따라 스캔 가능한 cloud로 표시한다.

## 사전 조건
- 같은 트랙 선행 step: FE-026 완료.
- mockable 외부 의존성: BE-016, AI-021. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page[data-page="report"]` 안 `.kw-cloud-v2`.
- 확정 변형 기준: `prototype/report-variations.jsx`의 `VariantCPlus`.
- 스타일 기준: `prototype/styles.css`의 `.kw-cloud-v2`와 `data-w` weight 표현.
- 보조 색인: `docs/design.md` §4.7, §5.4. 충돌 시 원본 prototype을 따른다.
- keyword weight별 font size, opacity, wrapping, section spacing을 prototype과 동일하게 맞춘다.

## 테스트 명세
- **테스트 파일**: `frontend/src/components/report/KeywordCloud.test.tsx`
- **테스트 이름**: `keyword_cloud_renders_keywords_with_weight_labels`
- **fixture**: keywords fixture: `{text:"AI", weight:5}`, `{text:"반도체", weight:3}`, `{text:"환율", weight:1}`을 사용한다.
- **action**: `KeywordCloud`를 렌더링한다.
- **assertions**:
  - list role 이름 `핵심 키워드`가 있다.
  - 텍스트 `AI`, `반도체`, `환율`이 보인다.
  - `AI` item의 aria-label에 `중요도 5`가 포함된다.
- **mock strategy**: 컴포넌트 props fixture만 사용한다. API 호출은 없다.
- **out of scope**: 키워드 클릭 검색과 필터링은 범위 밖이다.

## 구현 기준
- weight는 1~5 정수로 가정한다.
- CSS class는 weight bucket `weight-5` 형식으로 둔다.
