## 테스트 명세
- **테스트 파일**: `frontend/src/api/articles.test.ts`
- **테스트 이름**: `fetchArticle_returns_article_detail_contract`
- **fixture**: MSW `GET /api/articles/article_001` 응답에 `id`, `title`, `source`, `content`, `summary`, `publishedAt`, `category`를 둔다.
- **action**: `fetchArticle("article_001")`를 호출한다.
- **assertions**:
  - 반환 객체 id가 `article_001`이다.
  - `content`에 `본문 첫 문단`이 포함된다.
  - 404 응답은 `ArticleNotFoundError`를 throw한다.
- **mock strategy**: MSW node server를 사용한다. 실제 Spring 서버는 호출하지 않는다.
- **out of scope**: 상세 페이지 UI와 라우팅은 다음 step에서 구현한다.

## 구현 기준
- API 함수는 response status를 먼저 분기한다.
- date formatting은 fetcher가 아니라 view에서 처리한다.
