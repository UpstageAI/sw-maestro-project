# FE-029 - Report route navigation entry

## 목표
사용자가 bottom navigation 또는 feed entry에서 오늘 리포트로 이동할 수 있게 한다.

## 사전 조건
- 같은 트랙 선행 step: FE-028 완료.
- mockable 외부 의존성: BE-017, AI-022. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.bottom-nav`와 `.app-page[data-page="report"]`.
- 스타일 기준: `prototype/styles.css`의 `.bottom-nav`, `.nav-item`, `.nav-item--chat`.
- 보조 색인: `docs/design.md` §4.9, §5.1. 충돌 시 원본 prototype을 따른다.
- report navigation label, active state, icon size, 중앙 chat FAB 위치를 prototype과 동일하게 유지한다.

## 테스트 명세
- **테스트 파일**: `frontend/src/components/AppNavigation.test.tsx`
- **테스트 이름**: `bottom_navigation_has_today_report_link`
- **fixture**: 테스트 clock은 `2026-05-12T09:00:00+09:00`이고 navigation은 `/report/2026-05-12` href를 만든다.
- **action**: AppNavigation을 렌더링한다.
- **assertions**:
  - link role 이름 `오늘 리포트`가 있다.
  - 해당 link href가 `/report/2026-05-12`로 끝난다.
  - 현재 route가 report일 때 aria-current가 `page`이다.
- **mock strategy**: Clock/date helper를 fake로 주입한다. API 호출은 없다.
- **out of scope**: 캘린더형 과거 리포트 탐색은 범위 밖이다.

## 구현 기준
- 오늘 날짜 helper는 Asia/Seoul 기준으로 고정한다.
- mobile/desktop navigation 모두 같은 label을 사용한다.

- prototype bottom nav와 구현 nav를 나란히 비교한다.
- report nav item의 label, active state, icon 크기, 중앙 chat FAB 간격이 prototype과 같다.
