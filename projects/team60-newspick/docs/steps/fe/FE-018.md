# FE-018 - O/X 선택 상태와 정답 피드백

## 목표
사용자가 O 또는 X를 선택하면 정답 여부와 설명을 즉시 표시한다.

## 사전 조건
- 같은 트랙 선행 step: FE-017 완료.
- mockable 외부 의존성: BE-013, AI-015. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.inline-quiz#inlineQuiz`.
- 스타일 기준: `prototype/styles.css`의 `.ox-actions`, `.quiz-feedback`, `.quiz-feedback.is-correct`, `.quiz-feedback.is-wrong`.
- 인터랙션 기준: `prototype/script.js`의 `renderQuizQuestion`, `showQuizResult`.
- 보조 색인: `docs/design.md` §4.6, §6. 충돌 시 원본 prototype을 따른다.
- 선택 상태, 정답/오답 피드백 문구, role `status` 영역의 배치와 색상을 prototype과 동일하게 맞춘다.

## 테스트 명세
- **테스트 파일**: `frontend/src/components/InlineQuiz.test.tsx`
- **테스트 이름**: `selecting_correct_answer_shows_success_feedback`
- **fixture**: quiz fixture의 answer는 `true`, explanation은 `본문의 핵심 근거입니다`이다.
- **action**: `O` button을 클릭한다.
- **assertions**:
  - 텍스트 `정답입니다`가 보인다.
  - 텍스트 `본문의 핵심 근거입니다`가 보인다.
  - 선택된 `O` button의 `aria-pressed`가 `true`이다.
  - `X` button은 disabled 상태다.
- **mock strategy**: 컴포넌트 state만 검증한다. 서버 저장은 하지 않는다.
- **out of scope**: 다음 문항 이동과 결과 요약은 후속 step에서 구현한다.

## 구현 기준
- 오답 선택 테스트도 같은 파일에 추가해 `아쉽습니다` 문구를 검증한다.
- 피드백 영역은 role `status`로 둔다.

## 검증 방법

`cd frontend; pnpm lint`

- prototype `.inline-quiz#inlineQuiz`와 구현 컴포넌트를 나란히 비교한다.
- O/X 선택 후 selected 상태, 피드백 박스, 정답/오답 문구가 prototype과 같다.
- feedback 영역의 배경, radius, padding, 텍스트 굵기와 간격이 prototype과 같다.
