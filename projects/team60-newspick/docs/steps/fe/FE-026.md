# FE-026 - Report flow section

## 목표
Daily Report의 이슈 전개 흐름을 원인-전개-전망 구조로 보여준다.

## 사전 조건
- 같은 트랙 선행 step: FE-025 완료.
- mockable 외부 의존성: BE-016, AI-020. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## Prototype 기준
- 1차 기준: `prototype/index.html`의 `.app-page[data-page="report"]` 안 `.flow-list-v2`.
- 확정 변형 기준: `prototype/report-variations.jsx`의 `VariantCPlus`.
- 스타일 기준: `prototype/styles.css`의 `.flow-list-v2`, `.flow-row`, `.flow-cat`.
- 보조 색인: `docs/design.md` §4.7, §5.2. 충돌 시 원본 prototype을 따른다.
- 오늘의 흐름 row 3개, category label, 본문 line-height, row spacing을 prototype과 동일하게 맞춘다.
