- mockable 외부 의존성: BE-009, AI-009. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## 테스트 명세
- **테스트 파일**: `frontend/src/pages/ArticleDetailPage.test.tsx`
- **테스트 이름**: `article_detail_page_shows_loading_skeleton_before_content`
- **fixture**: MSW 상세 handler가 500ms delay 후 `article_001` detail을 반환한다.
- **action**: `/articles/article_001` 렌더 직후와 응답 후를 순서대로 관찰한다.
- **assertions**:
  - 초기 화면에 role `status` 이름 `기사 불러오는 중`이 있다.
  - 초기 skeleton block이 3개이다.
  - 응답 후 role `status`가 사라지고 heading이 보인다.
- **mock strategy**: MSW delay를 사용한다. 실제 네트워크 지연은 사용하지 않는다.
- **out of scope**: 피드 loading과 error는 이 단계에서 바꾸지 않는다.

## 구현 기준
- skeleton은 layout shift가 없도록 고정 height를 둔다.
- aria-busy를 본문 영역에 설정한다.
