- mockable 외부 의존성: BE-009, AI-009. 미완료 상태에서도 MSW 또는 fixture로 진행한다.
- hard 외부 의존성 없음.

## 테스트 명세
- **테스트 파일**: `frontend/src/pages/FeedPage.test.tsx`
- **테스트 이름**: `renders_three_article_cards_from_msw_feed`
- **fixture**: MSW `GET /api/feed` 응답 `{articles:[article_001, article_002, article_003]}`. 각 article은 `id`, `title`, `source`, `summary`, `publishedAt`, `category`를 가진다.
- **action**: React Testing Library로 `/feed` route의 `FeedPage`를 렌더링한다.
- **assertions**:
  - role `article` 요소가 3개이다.
  - 화면에 `AI가 바꾼 뉴스 소비`, `Example News`, `2026.05.12`가 보인다.
  - 각 카드의 링크 role 이름이 기사 title을 포함한다.
- **mock strategy**: MSW handler를 사용한다. 실제 BE/AI 서버는 호출하지 않는다.
- **out of scope**: 상세 페이지 이동, skeleton, error 상태는 후속 step에서 구현한다.

## 구현 기준
- Feed fetcher는 기존 `api` helper 패턴을 따른다.
- 카드 data-testid는 쓰지 않고 role/name 우선으로 검증한다.
