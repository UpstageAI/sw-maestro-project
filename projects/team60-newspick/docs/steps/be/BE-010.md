# BE-010 - Article detail full content 조회

## 목표
상세 API에서 본문 content와 summary를 포함한 article detail DTO를 반환한다.

## 사전 조건
- 같은 트랙 선행 step: BE-009 완료.
- mockable 외부 의존성 없음.
- hard 외부 의존성 없음.

## 파일 대상
```text
[수정] backend/src/main/java/com/newspick/article/ArticleController.java
[수정] backend/src/main/java/com/newspick/article/ArticleService.java
[신규] backend/src/test/java/com/newspick/article/ArticleDetailIntegrationTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/article/ArticleDetailIntegrationTest.java`
- **테스트 이름**: `getArticle_returns_full_content_from_database`
- **fixture**: Testcontainers DB에 `article_001` content `본문 첫 문단

본문 둘째 문단`, summary `핵심 요약`을 저장한다.
- **action**: MockMvc로 `GET /api/articles/article_001`를 호출한다.
- **assertions**:
  - HTTP 200이다.
  - `$.id`가 `article_001`이다.
  - `$.content`에 `본문 첫 문단`이 포함된다.
  - `$.summary`가 `핵심 요약`이다.
- **mock strategy**: Repository mock을 쓰지 않는다. Flyway 적용 Testcontainers DB를 사용한다.
- **out of scope**: quiz, related articles, chat article card는 포함하지 않는다.

## 구현 기준
- content는 DB 값을 그대로 반환한다.
- 존재하지 않는 id는 BE-005의 404 정책을 유지한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ArticleDetailIntegrationTest"`
