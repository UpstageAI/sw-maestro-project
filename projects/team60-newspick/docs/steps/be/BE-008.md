# BE-008 - GET /api/report/today 빈 결과 처리

## 목표
Daily Report 조회 endpoint의 기본 경로와 비어 있는 날짜 처리 정책을 고정한다.

## 사전 조건
- `BE-007`의 SSE proxy 테스트가 통과한다.
- `docs/contracts/openapi.yaml`의 report endpoint path를 따른다.

## 파일 대상
```text
[신규] backend/src/main/java/com/newspick/report/DailyReport.java
[신규] backend/src/main/java/com/newspick/report/DailyReportRepository.java
[신규] backend/src/main/java/com/newspick/report/ReportController.java
[신규] backend/src/test/java/com/newspick/report/ReportControllerTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/report/ReportControllerTest.java`
- **테스트 이름**: `getTodayReport_whenMissing_returns404ReportNotReady`
- **fixture**: `DailyReportRepository` mock이 오늘 날짜 `2026-05-12`에 대해 `Optional.empty()`를 반환한다. 테스트 clock은 `2026-05-12T00:00:00+09:00`으로 고정한다.
- **action**: MockMvc로 `GET /api/report/today`를 호출한다.
- **assertions**:
  - HTTP 404를 반환한다.
  - `$.code`가 `REPORT_NOT_READY`이다.
  - `$.date`가 `2026-05-12`이다.
- **mock strategy**: Controller slice 테스트에서 repository 또는 service를 Mockito mock으로 고정한다. DB는 사용하지 않는다.
- **out of scope**: 리포트 전체 DTO와 날짜별 `/api/report/{date}`는 `BE-015` 이후에 구현한다.

## 구현 기준
- Clock bean을 주입해 오늘 날짜를 테스트에서 고정한다.
- 빈 결과는 빈 객체가 아니라 404 error envelope로 반환한다.
- `DailyReport` entity는 `report_date` unique 제약을 반영한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ReportControllerTest"`
