# BE-013 - Article detail quiz DTO 반환

## 사전 조건

- mockable 외부 의존성: AI-015. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

```text
[수정] backend/src/main/java/com/newspick/article/ArticleDetailResponse.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/article/ArticleQuizDtoTest.java`
- **테스트 이름**: `article_detail_response_includes_quiz_items`
- **fixture**: quiz fixture `quiz_001` question `본문 내용은 사실이다`, answer true, explanation `본문 근거`를 사용한다.
- **action**: ArticleDetailResponse mapper를 호출한다.
- **assertions**:
  - `quizzes[0].id`가 `quiz_001`이다.
  - `quizzes[0].answer`가 boolean true이다.
  - `quizzes[0].explanation`이 `본문 근거`이다.
- **mock strategy**: Mapper 단위 테스트와 in-memory fixture를 사용한다. DB는 호출하지 않는다.
- **out of scope**: quiz 생성 AI 호출과 저장 schema 변경은 이 단계에서 다루지 않는다.

## 구현 기준
- quiz가 없으면 빈 배열을 반환한다.
- field 이름은 FE InlineQuiz fixture와 동일하게 유지한다.
