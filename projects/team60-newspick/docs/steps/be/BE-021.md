# BE-021 - chat error proxy

## 목표
Python chat-stream 오류를 FE가 처리 가능한 SSE error 이벤트로 변환한다.

## 사전 조건
- 같은 트랙 선행 step: BE-020 완료.
- mockable 외부 의존성: AI-027. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[수정] backend/src/main/java/com/newspick/chat/ChatController.java
[수정] backend/src/test/java/com/newspick/chat/ChatControllerTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/chat/ChatControllerTest.java`
- **테스트 이름**: `chatStream_whenPythonFails_emits_error_event`
- **fixture**: PythonChatClient mock이 `ChatStreamException("timeout")`을 던진다.
- **action**: `POST /api/chat-stream`를 호출한다.
- **assertions**:
  - HTTP 200 SSE 응답을 유지한다.
  - 본문에 `event: error`가 있다.
  - data code가 `CHAT_STREAM_FAILED`이다.
  - stack trace 문자열이 응답에 없다.
- **mock strategy**: PythonChatClient mock으로 실패를 만든다. 실제 timeout은 발생시키지 않는다.
- **out of scope**: 클라이언트 재시도 정책은 FE-035에서 구현한다.

## 구현 기준
- error event 뒤에는 stream을 종료한다.
- message는 사용자 표시 가능한 한국어 문장으로 둔다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ChatControllerTest"`
