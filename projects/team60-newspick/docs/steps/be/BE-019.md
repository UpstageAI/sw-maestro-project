# BE-019 - POST /api/chat-stream proxy 기본

## 목표
프론트엔드 chat 요청을 Python chat-stream으로 프록시한다.

## 사전 조건
- 같은 트랙 선행 step: BE-018 완료.
- mockable 외부 의존성: AI-024. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[신규] backend/src/main/java/com/newspick/chat/ChatController.java
[신규] backend/src/test/java/com/newspick/chat/ChatControllerTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/chat/ChatControllerTest.java`
- **테스트 이름**: `chatStream_proxies_token_event`
- **fixture**: PythonChatClient mock이 token event data `{text:"안녕"}`와 done event `{articles:[]}`를 반환한다.
- **action**: MockMvc async request로 `POST /api/chat-stream` body `{message:"오늘 뉴스"}`를 보낸다.
- **assertions**:
  - HTTP 200과 `text/event-stream` content type을 반환한다.
  - 응답 본문에 `event: token`과 `안녕`이 있다.
  - 응답 본문에 `event: done`이 있다.
- **mock strategy**: PythonChatClient를 Mockito mock으로 고정한다. 실제 Python 서버는 호출하지 않는다.
- **out of scope**: error event와 article card schema는 후속 step에서 다룬다.

## 구현 기준
- 빈 message는 400을 반환한다.
- event 이름과 data는 Python 응답을 그대로 전달한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ChatControllerTest"`
