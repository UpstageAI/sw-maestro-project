# BE-018 - Python chat client request 모델

## 목표
Spring에서 Python `/chat-stream`으로 보낼 request DTO와 client method를 만든다.

## 사전 조건
- 같은 트랙 선행 step: BE-017 완료.
- mockable 외부 의존성: AI-024. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[신규] backend/src/main/java/com/newspick/chat/ChatRequest.java
[신규] backend/src/main/java/com/newspick/ai/PythonChatClient.java
[신규] backend/src/test/java/com/newspick/ai/PythonChatClientTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/ai/PythonChatClientTest.java`
- **테스트 이름**: `chatStream_posts_message_and_reads_token_event`
- **fixture**: WireMock이 `POST /chat-stream` request body `{message:"오늘 뉴스"}`를 받고 token SSE를 반환한다.
- **action**: `PythonChatClient.chatStream(new ChatRequest("오늘 뉴스"))`를 구독한다.
- **assertions**:
  - WireMock request body `$.message`가 `오늘 뉴스`이다.
  - 첫 이벤트 이름이 `token`이다.
  - 첫 이벤트 data에 `안녕하세요`가 포함된다.
- **mock strategy**: WireMock으로 Python 서버를 대체한다. DB는 호출하지 않는다.
- **out of scope**: Spring `/api/chat-stream` proxy endpoint는 BE-019에서 구현한다.

## 구현 기준
- SSE 수신은 WebClient로 구현한다.
- request field는 `message`, `contextArticleIds`로 고정한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*PythonChatClientTest"`
