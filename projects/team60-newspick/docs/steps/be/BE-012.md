# BE-012 - Article detail contract fixture 검증

## 목표
FE live gate가 사용할 article detail fixture와 Spring 응답을 동일 필드로 고정한다.

## 사전 조건
- 같은 트랙 선행 step: BE-011 완료.
- mockable 외부 의존성: AI-014. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[신규] backend/src/test/java/com/newspick/article/ArticleDetailContractTest.java
[신규] backend/src/test/resources/contracts/article-detail.article_001.json
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/article/ArticleDetailContractTest.java`
- **테스트 이름**: `article_detail_response_matches_contract_fixture`
- **fixture**: DB seed `article_001`과 contract fixture `article-detail.article_001.json`을 사용한다.
- **action**: MockMvc로 `GET /api/articles/article_001` 호출 후 JSONAssert strict=false로 비교한다.
- **assertions**:
  - HTTP 200이다.
  - fixture required field `id`, `title`, `source`, `publishedAt`, `content`, `summary`가 응답에 있다.
  - 날짜 format이 ISO-8601 문자열이다.
- **mock strategy**: Testcontainers DB를 사용한다. AI-014 산출물은 fixture로 대체한다.
- **out of scope**: 실제 AI 서버 호출은 하지 않는다.

## 구현 기준
- AI-014 미완료 상태에서는 fixture 기반으로 진행한다.
- FE-016 live gate 전에는 이 테스트가 통과해야 한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ArticleDetailContractTest"`
