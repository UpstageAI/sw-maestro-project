# BE-016 - Daily Report full DTO mapping

## 목표
daily report 응답에 timeline, flow, keywords 전체 구조를 포함한다.

## 사전 조건
- 같은 트랙 선행 step: BE-015 완료.
- mockable 외부 의존성: AI-021. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[수정] backend/src/main/java/com/newspick/report/DailyReportResponse.java
[신규] backend/src/test/java/com/newspick/report/DailyReportDtoTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/report/DailyReportDtoTest.java`
- **테스트 이름**: `daily_report_response_maps_timeline_flow_keywords`
- **fixture**: DailyReport fixture는 timeline 3개, flow steps 3개, keywords 3개를 가진 JSON payload다.
- **action**: mapper를 호출해 DailyReportResponse로 변환한다.
- **assertions**:
  - timeline size가 3이다.
  - flow 첫 step label이 `원인`이다.
  - keywords 첫 item text가 `AI`이고 weight가 5이다.
- **mock strategy**: Mapper 단위 테스트와 fixture JSON을 사용한다. DB는 호출하지 않는다.
- **out of scope**: 404/error 처리와 contract fixture는 BE-017에서 다룬다.

## 구현 기준
- payload JSON field는 `briefing`, `timeline`, `flow`, `keywords`로 고정한다.
- unknown field는 무시하지 않고 테스트 fixture에서 제거한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*DailyReportDtoTest"`
