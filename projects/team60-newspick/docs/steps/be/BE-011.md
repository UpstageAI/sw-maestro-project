# BE-011 - Article detail 404 fixture 검증

## 목표
상세 API의 404 error envelope을 계약 fixture와 맞춘다.

## 사전 조건
- 같은 트랙 선행 step: BE-010 완료.
- mockable 외부 의존성 없음.
- hard 외부 의존성 없음.

## 파일 대상
```text
[수정] backend/src/test/java/com/newspick/article/ArticleControllerTest.java
[신규] backend/src/test/resources/contracts/article-not-found.json
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/article/ArticleControllerTest.java`
- **테스트 이름**: `getArticle_missing_matches_article_not_found_contract`
- **fixture**: contract fixture `{code:"ARTICLE_NOT_FOUND", message:"기사를 찾을 수 없습니다"}`를 사용한다.
- **action**: MockMvc로 missing id를 호출하고 JSONAssert로 fixture와 비교한다.
- **assertions**:
  - HTTP status가 404이다.
  - 응답 JSON이 fixture의 `code`, `message`를 포함한다.
  - 불필요한 stack trace 필드가 없다.
- **mock strategy**: Controller slice 테스트와 service mock을 사용한다. DB는 호출하지 않는다.
- **out of scope**: 성공 응답 schema 검증은 BE-012에서 수행한다.

## 구현 기준
- error response content type은 `application/json`이다.
- message는 사용자 표시 가능한 한국어 문장이다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ArticleControllerTest"`
