# BE-015 - GET /api/report/{date} 기본 DTO

## 목표
날짜별 daily report endpoint와 기본 briefing DTO를 구현한다.

## 사전 조건
- 같은 트랙 선행 step: BE-014 완료.
- mockable 외부 의존성: AI-018. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[수정] backend/src/main/java/com/newspick/report/ReportController.java
[수정] backend/src/main/java/com/newspick/report/DailyReport.java

```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/report/ReportByDateControllerTest.java`
- **테스트 이름**: `getReportByDate_returns_briefing`
- **fixture**: repository mock이 date `2026-05-12`에 headline `오늘의 핵심`, summary `세 가지 흐름`을 가진 report를 반환한다.
- **action**: MockMvc로 `GET /api/report/2026-05-12`를 호출한다.
- **assertions**:
  - HTTP 200이다.
  - `$.date`가 `2026-05-12`이다.
  - `$.briefing.headline`이 `오늘의 핵심`이다.
  - `$.briefing.summary`가 `세 가지 흐름`이다.
- **mock strategy**: Controller/service 테스트는 repository mock을 사용한다. DB는 호출하지 않는다.
- **out of scope**: timeline, flow, keywords는 BE-016에서 확장한다.

## 구현 기준
- date path variable은 `yyyy-MM-dd`만 허용한다.
- 잘못된 date는 400을 반환한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ReportByDateControllerTest"`
