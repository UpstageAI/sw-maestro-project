# BE-007 - GET /api/refresh-stream SSE 프록시

## 목표
프론트엔드가 Spring의 `/api/refresh-stream`만 바라보면 Python AI 진행 이벤트를 받을 수 있게 한다.

## 사전 조건
- `BE-006`의 PythonAiClient가 WireMock SSE를 읽는다.
- `docs/contracts/sse-events.md`의 `refresh-stream` 이벤트 이름을 따른다.

## 파일 대상
```text
[신규] backend/src/main/java/com/newspick/pipeline/PipelineController.java
[신규] backend/src/test/java/com/newspick/pipeline/PipelineControllerTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/pipeline/PipelineControllerTest.java`
- **테스트 이름**: `refreshStream_proxiesStepAndDoneEvents`
- **fixture**: `PythonAiClient` mock이 `step` 이벤트 data `{"stage":"summarize"}`와 `done` 이벤트 data `{"articleIds":["article_001"]}`를 순서대로 반환한다.
- **action**: MockMvc async request로 `GET /api/refresh-stream`를 호출하고 async dispatch 결과를 읽는다.
- **assertions**:
  - HTTP 200과 `text/event-stream` content type을 반환한다.
  - 응답 본문에 `event: step`이 있다.
  - 응답 본문에 `summarize`가 있다.
  - 응답 본문에 `event: done`과 `article_001`이 있다.
- **mock strategy**: `PythonAiClient`를 Mockito mock으로 고정한다. Python 서버와 DB는 호출하지 않는다.
- **out of scope**: refresh 버튼 UI와 actual AI graph 실행은 이 단계에서 다루지 않는다.

## 구현 기준
- Spring WebFlux controller 또는 MVC async streaming 중 하나를 선택해 테스트가 안정적으로 통과하게 한다.
- 이벤트 이름과 data 문자열은 변경하지 않고 전달한다.
- 클라이언트 오류는 `event: error`로 변환한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*PipelineControllerTest"`
