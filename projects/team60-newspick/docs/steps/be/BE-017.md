# BE-017 - Daily Report 404/error contract

## 목표
Daily Report full response와 404 error를 contract fixture 기준으로 고정한다.

## 사전 조건
- 같은 트랙 선행 step: BE-016 완료.
- mockable 외부 의존성: AI-023. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[신규] backend/src/test/java/com/newspick/report/DailyReportContractTest.java
[신규] backend/src/test/resources/contracts/daily-report.2026-05-12.json
[신규] backend/src/test/resources/contracts/report-not-ready.2026-05-13.json
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/report/DailyReportContractTest.java`
- **테스트 이름**: `daily_report_response_and_404_match_contract_fixtures`
- **fixture**: DB seed `2026-05-12` report와 missing date `2026-05-13` fixture를 사용한다.
- **action**: MockMvc로 두 날짜를 각각 호출한다.
- **assertions**:
  - 성공 응답은 HTTP 200이고 daily-report fixture required field를 가진다.
  - missing 응답은 HTTP 404이고 `REPORT_NOT_READY` code를 가진다.
  - 성공 응답의 keywords item은 `text`, `weight`를 가진다.
- **mock strategy**: Testcontainers DB를 사용한다. AI-023 산출물은 fixture로 대체한다.
- **out of scope**: 실제 AI report 생성 호출은 하지 않는다.

## 구현 기준
- FE-030 live gate 전에는 이 테스트가 통과해야 한다.
- 404 날짜는 response body `date`에 그대로 넣는다.

## 검증 방법
`cd backend; ./gradlew test --tests "*DailyReportContractTest"`
