# BE-004 - DB 기반 Feed 요약 목록 조회

## 목표
`articles` 테이블의 요약 완료 기사만 `/api/feed` 목록으로 노출한다.

## 사전 조건
- `BE-003`의 `/api/feed` endpoint가 빈 목록을 반환한다.
- `BE-002`의 ArticleRepository 저장/조회가 통과한다.

## 파일 대상
```text
[수정] backend/src/main/java/com/newspick/feed/FeedService.java
[신규] backend/src/test/java/com/newspick/feed/FeedIntegrationTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/feed/FeedIntegrationTest.java`
- **테스트 이름**: `getFeed_returnsSummarizedArticlesOrderedByPublishedAtDesc`
- **fixture**: Testcontainers DB에 `article_recent`, `article_old` status `summarized` 2건과 `article_raw` status `collected` 1건을 저장한다.
- **action**: MockMvc로 `GET /api/feed`를 호출한다.
- **assertions**:
  - HTTP 200을 반환한다.
  - `$.articles.length()`가 `2`이다.
  - `$.articles[0].id`가 `article_recent`이다.
  - `$.articles[*].id`에 `article_raw`가 없다.
- **mock strategy**: Repository mock을 쓰지 않는다. Flyway가 적용된 Testcontainers PostgreSQL을 사용한다.
- **out of scope**: article detail 본문과 quiz/report DTO는 이 단계에서 반환하지 않는다.

## 구현 기준
- Repository query는 `status = summarized` 조건과 `published_at DESC` 정렬을 가진다.
- summary 문장은 nullable이면 빈 문자열이 아니라 `null`로 매핑한다.
- 카테고리 필터 파라미터는 구현하지 않는다.

## 검증 방법
`cd backend; ./gradlew test --tests "*FeedIntegrationTest"`
