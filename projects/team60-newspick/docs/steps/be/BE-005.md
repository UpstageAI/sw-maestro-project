# BE-005 - GET /api/articles/{id} 상세 기본 응답과 404

## 목표
기사 상세 endpoint의 기본 경로를 열고 존재하지 않는 id에는 404를 반환한다.

## 사전 조건
- `BE-004`의 feed 목록 DTO가 동작한다.
- `docs/contracts/openapi.yaml`의 `/api/articles/{id}` 상태 코드를 따른다.

## 파일 대상
```text
[신규] backend/src/main/java/com/newspick/article/ArticleController.java
[신규] backend/src/main/java/com/newspick/article/ArticleService.java
[신규] backend/src/test/java/com/newspick/article/ArticleControllerTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/article/ArticleControllerTest.java`
- **테스트 이름**: `getArticle_whenMissing_returns404JsonError`
- **fixture**: `ArticleService` mock이 `missing-id`에 대해 `Optional.empty()`를 반환한다.
- **action**: MockMvc로 `GET /api/articles/missing-id`를 호출한다.
- **assertions**:
  - HTTP 404를 반환한다.
  - `$.code`가 `ARTICLE_NOT_FOUND`이다.
  - `$.message`가 빈 문자열이 아니다.
- **mock strategy**: Controller slice 테스트에서 `ArticleService`를 Mockito mock으로 고정한다.
- **out of scope**: 본문 content, quiz, related articles는 M3/M4/M6 후속 단계에서 확장한다.

## 구현 기준
- 에러 DTO는 공용 `ApiErrorResponse`로 둔다.
- 존재하는 기사 200 케이스는 같은 테스트 파일의 보조 테스트로 `id`, `title`, `source`만 검증한다.
- Controller path는 `/api/articles/{id}`이다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ArticleControllerTest"`
