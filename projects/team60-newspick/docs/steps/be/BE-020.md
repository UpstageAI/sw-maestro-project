## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/chat/ChatStreamContractTest.java`
- **테스트 이름**: `chat_stream_done_articles_match_article_card_summary_contract`
- **fixture**: PythonChatClient mock은 token 2개와 done `{articles:[{id,title,source,publishedAt}]}`를 반환한다.
- **action**: `POST /api/chat-stream` 호출 결과 SSE 본문을 파싱한다.
- **assertions**:
  - token event가 2개이다.
  - done event가 1개이다.
  - done articles 첫 item에 `id`, `title`, `source`, `publishedAt`이 있다.
- **mock strategy**: PythonChatClient mock을 사용한다. AI-029 실제 retrieval은 호출하지 않는다.
- **out of scope**: 에러 프록시는 BE-021에서 구현한다.

## 구현 기준

- FE-034가 이 fixture를 사용할 수 있게 event 순서를 고정한다.
