# BE-023 - chat live proxy readiness contract

## 목표
FE-037 live gate 전에 Spring chat proxy가 token/done/error 계약을 모두 만족하는지 검증한다.

## 사전 조건
- 같은 트랙 선행 step: BE-022 완료.
- mockable 외부 의존성: AI-029. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[신규] backend/src/test/java/com/newspick/chat/ChatLiveReadinessContractTest.java
[신규] backend/src/test/resources/contracts/article-card-summary.valid.json
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/chat/ChatLiveReadinessContractTest.java`
- **테스트 이름**: `chat_proxy_contract_supports_token_done_and_error_events`
- **fixture**: WireMock Python server가 success stream과 error stream 두 endpoint fixture를 제공한다.
- **action**: Spring test profile에서 Python base URL을 WireMock으로 바꾸고 `/api/chat-stream`을 두 번 호출한다.
- **assertions**:
  - success stream은 token 1개 이상과 done 1개를 반환한다.
  - done articles item은 ArticleCardSummary required field를 가진다.
  - error stream은 `CHAT_STREAM_FAILED` code를 반환한다.
- **mock strategy**: WireMock으로 Python AI를 대체한다. 실제 AI 서버는 FE-037 live mode 전까지 호출하지 않는다.
- **out of scope**: FE 브라우저 테스트는 이 단계에서 실행하지 않는다.

## 구현 기준
- AI-029 완료 후 실제 서버 smoke는 `RUN_LIVE_CONTRACT=true`에서 수행한다.
- FE-037 hard dependency로 이 step이 사용된다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ChatLiveReadinessContractTest"`
