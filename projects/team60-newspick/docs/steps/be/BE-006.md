# BE-006 - PythonAiClient refresh-stream 클라이언트

## 목표
Spring 서버가 Python AI 서버의 `/refresh-stream` SSE를 읽을 수 있는 클라이언트를 만든다.

## 사전 조건
- `AI-007`이 아직 없어도 WireMock SSE fixture로 테스트한다.
- `docs/contracts/python-ai.yaml`의 `/refresh-stream` 이벤트 이름을 따른다.

## 파일 대상
```text
[신규] backend/src/main/java/com/newspick/ai/PythonAiClient.java
[신규] backend/src/main/java/com/newspick/ai/PythonAiProperties.java
[신규] backend/src/test/java/com/newspick/ai/PythonAiClientTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/ai/PythonAiClientTest.java`
- **테스트 이름**: `refreshStream_readsStepAndDoneEventsFromWireMock`
- **fixture**: WireMock이 `GET /refresh-stream`에 `text/event-stream`으로 `event: step` data `{"stage":"collect"}`와 `event: done` data `{"articleIds":["article_001"]}`를 반환한다.
- **action**: `PythonAiClient.refreshStream()`을 구독해 두 이벤트를 수집한다.
- **assertions**:
  - 첫 이벤트 이름이 `step`이다.
  - 첫 이벤트 data에 `collect`가 포함된다.
  - 마지막 이벤트 이름이 `done`이다.
  - 마지막 이벤트 data에 `article_001`이 포함된다.
- **mock strategy**: 실제 Python 서버를 호출하지 않는다. WireMock으로 HTTP SSE 응답을 고정한다.
- **out of scope**: 브라우저로 SSE를 다시 프록시하는 API는 `BE-007`에서 구현한다.

## 구현 기준
- SSE 수신은 `WebClient`와 `Flux<ServerSentEvent<String>>`로 구현한다.
- `python-ai.base-url` property를 둔다.
- timeout은 테스트에서 2초 이하로 고정한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*PythonAiClientTest"`
