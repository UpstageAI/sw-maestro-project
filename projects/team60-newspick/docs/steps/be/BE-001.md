# BE-001 — Flyway V1 init 마이그레이션

## 목표

Spring Boot 가 시작 시 `articles` 와 `daily_reports` 테이블을 자동 생성한다 (Flyway V1__init.sql 적용). 통합 테스트에서 새 빈 DB 가 마이그레이션 후 두 테이블이 존재하는지 검증.

## 사전 조건

- BOOT-000 완료
- `backend/src/main/resources/db/migration/V1__init.sql` 가 `docs/contracts/db-init.sql` 와 **동일한 내용** (BOOT-000 에서 복사함)
- 로컬 DB 컨테이너 실행 중

## 파일 대상

```
backend/src/main/resources/db/migration/V1__init.sql                         [확인 — 변경 X]

backend/src/test/java/com/newspick/MigrationIntegrationTest.java             [신규]
backend/src/test/resources/application-test.yml                              [신규]
backend/build.gradle                                                          [수정 — testcontainers 의존성]
```

## 테스트 명세

- **테스트 파일**: `backend/src/test/java/com/newspick/MigrationIntegrationTest.java`
- **테스트 이름**: `flyway_appliesV1_creates_articles_and_daily_reports_tables`
- **given**: Testcontainers `pgvector/pgvector:pg16` 컨테이너 새로 기동, Flyway 미적용 상태
- **when**: Spring Boot 가 컨텍스트 로딩 (Flyway 자동 실행)
- **then**:
  - `information_schema.tables` 에 `articles`, `daily_reports` 두 테이블이 존재
  - `articles.embedding` 컬럼 데이터 타입이 `vector` (udt_name)
  - `articles.id` PRIMARY KEY 제약 존재

## 구현 힌트

- `@SpringBootTest` + `@Testcontainers` 사용. `PostgreSQLContainer` 는 `pgvector/pgvector:pg16` 이미지로 띄우고 `@DynamicPropertySource` 로 datasource URL 주입.
- Flyway 설정: `application.yml` 에 `spring.flyway.enabled=true`, `baseline-on-migrate=true`, `locations=classpath:db/migration`.
- 테스트는 `JdbcTemplate` 으로 `information_schema` 조회.
- 의존성:
  ```groovy
  testImplementation 'org.testcontainers:postgresql:1.20.4'
  testImplementation 'org.testcontainers:junit-jupiter:1.20.4'
  testImplementation 'org.springframework.boot:spring-boot-testcontainers'
  ```
- Testcontainers 가 사용하는 이미지는 `pgvector` 확장 미리 설치되어 있어 `CREATE EXTENSION vector` 가 통과.

## 검증 방법

**자동**:
```bash
cd backend
./gradlew :test --tests com.newspick.MigrationIntegrationTest
```
기대: 1 test pass.

**수동**:
```bash
docker compose up -d
cd backend && ./gradlew bootRun
# 다른 터미널
docker exec -it newspick-db psql -U newspick -d newspick -c "\dt"
```
기대: `articles`, `daily_reports`, `flyway_schema_history` 3개 테이블 표시.

## 결정 완료 테스트 명세

- **테스트 이름**: `flyway_migration_creates_articles_daily_reports_and_pgvector`
- **fixture**: Testcontainers PostgreSQL 16과 `docs/contracts/db-init.sql` 기반 V1 migration.
- **action**: Spring test context에서 Flyway migration을 실행한 뒤 information_schema와 extension catalog를 조회한다.
- **assertions**:
  - `articles` table이 존재한다.
  - `daily_reports` table이 존재한다.
  - `vector` extension이 활성화되어 있다.
  - `articles.url` unique constraint가 존재한다.
- **mock strategy**: DB는 Testcontainers PostgreSQL을 사용한다. FE/AI 서버는 호출하지 않는다.
- **out of scope**: JPA entity, repository, API endpoint는 BE-002 이후에서 구현한다.
