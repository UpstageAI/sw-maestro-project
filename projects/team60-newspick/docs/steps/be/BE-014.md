# BE-014 - Quiz mapping contract test

## 목표
저장된 quiz payload가 article detail 응답으로 안정적으로 매핑되는지 검증한다.

## 사전 조건
- 같은 트랙 선행 step: BE-013 완료.
- mockable 외부 의존성: AI-017. 미완료 상태에서는 WireMock, fixture, repository mock으로 대체한다.
- hard 외부 의존성 없음.

## 파일 대상
```text
[신규] backend/src/test/java/com/newspick/article/ArticleQuizContractTest.java
[신규] backend/src/test/resources/contracts/article-detail-with-quiz.article_001.json
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/article/ArticleQuizContractTest.java`
- **테스트 이름**: `article_detail_with_quiz_matches_contract_fixture`
- **fixture**: Testcontainers DB에 `article_001`과 quiz JSON 2개를 저장하고 contract fixture와 비교한다.
- **action**: MockMvc로 `GET /api/articles/article_001`를 호출한다.
- **assertions**:
  - HTTP 200이다.
  - `$.quizzes.length()`가 2이다.
  - 각 quiz에 `id`, `question`, `answer`, `explanation`이 있다.
  - fixture와 응답의 quiz id 순서가 같다.
- **mock strategy**: Testcontainers DB를 사용한다. AI-017 결과는 fixture JSON으로 대체한다.
- **out of scope**: 실제 quiz generator 호출은 하지 않는다.

## 구현 기준
- quiz 순서는 DB 저장 순서 또는 `order` 컬럼으로 고정한다.
- FE-022 live gate 전에는 이 테스트가 통과해야 한다.

## 검증 방법
`cd backend; ./gradlew test --tests "*ArticleQuizContractTest"`
