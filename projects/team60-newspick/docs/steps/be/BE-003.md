# BE-003 - GET /api/feed 빈 목록 응답

## 목표
아직 기사 데이터가 없을 때 `/api/feed`가 계약 형식의 빈 배열을 반환하게 한다.

## 사전 조건
- `BE-002`의 ArticleRepository가 존재한다.
- `docs/contracts/openapi.yaml`의 `/api/feed` 응답 envelope을 따른다.

## 파일 대상
```text
[신규] backend/src/main/java/com/newspick/feed/FeedController.java
[신규] backend/src/main/java/com/newspick/feed/FeedService.java
[신규] backend/src/test/java/com/newspick/feed/FeedControllerTest.java
```

## 테스트 명세
- **테스트 파일**: `backend/src/test/java/com/newspick/feed/FeedControllerTest.java`
- **테스트 이름**: `getFeed_whenNoArticles_returnsEmptyArticlesArray`
- **fixture**: `FeedService` mock이 빈 `List<ArticleSummaryDto>`를 반환한다.
- **action**: MockMvc로 `GET /api/feed`를 호출한다.
- **assertions**:
  - HTTP 200을 반환한다.
  - JSON path `$.articles`가 배열이다.
  - `$.articles.length()`가 `0`이다.
- **mock strategy**: Controller slice 테스트에서 `FeedService`를 Mockito mock으로 고정한다.
- **out of scope**: DB 정렬, 카테고리 필터, 상세 본문 조회는 이 단계에서 구현하지 않는다.

## 구현 기준
- 응답 DTO 이름은 `FeedResponse`로 둔다.
- 빈 목록을 `null`로 반환하지 않는다.
- Controller base path는 `/api`로 둔다.

## 검증 방법
`cd backend; ./gradlew test --tests "*FeedControllerTest"`
