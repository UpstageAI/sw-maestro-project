# NewPick 개요

## 프로젝트 성격

NewPick은 3주간 진행하는 AI 기술 경험용 프로젝트다. 로컬 환경에서 실행하며 발표 1회로 마무리한다. 서비스 운영을 전제로 하지 않으므로 UX 완성도보다 AI 파이프라인 동작 증명과 시연 완성도에 집중한다.

이 전제에 따라 다음 기능은 구현하지 않기로 확정했다.

- 카테고리 변경 UX: 온보딩에서 1회 선택으로 충분하다.
- 요약 오류 신고: 운영 중 필요한 기능이며 발표 범위 밖이다.
- 요약 처리 상태 UI (요약 중 / 검토 필요 배지): 발표 시나리오에서 불필요하다.

## 앱 기획 요약

NewPick은 RSS 기반 뉴스를 카테고리별로 수집하고, AI가 핵심 내용을 요약한 뒤 O/X 퀴즈로 이해도를 확인하게 하는 개인화 뉴스 브리핑 서비스다.

핵심 사용 흐름은 다음과 같다.

1. 사용자가 관심 카테고리를 선택한다.
2. 선택한 카테고리의 RSS 기사 요약 카드가 홈 피드에 표시된다.
3. 사용자는 기사 상세에서 AI 요약, 원문 링크, 핵심 맥락을 확인한다.
4. 상세 화면 안에서 O/X 퀴즈 3문항을 풀고 즉시 피드백을 받는다.
5. 리포트 화면에서 하루 단위 주요 이슈를 확인한다.
6. AI 어시스턴트에게 수집된 기사·리포트를 자연어로 질문한다.

기획의 핵심 가치는 뒤섞인 뉴스 피드가 아니라, 사용자가 선택한 분야의 기사만 빠르게 이해하고 기억하게 돕는 것이다.
